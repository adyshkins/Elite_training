## Цель

Перенести операции хранения данных в Go-приложение.

## Планируемая работа на занятии

1. Добавить GORM и драйвер PostgreSQL, получить параметры подключения из конфигурации.
2. Описать модели проекта и задачи, разобрать учебные миграции и ограничения автоматического изменения схемы.
3. Реализовать CRUD и обработку отсутствующей записи.
4. Загрузить связанные данные, проверить их сохранность после перезапуска приложения.

## Ожидаемый результат

Go-приложение, сохраняющее и получающее связанные данные из PostgreSQL.

## Самостоятельная часть и расширение

Дописать операции и проверить связи. Разобрать особенности обновления нулевых значений выбранными методами GORM.
