## Цель

Понять путь HTTP-запроса и создать минимальный сервер без фреймворка.

## Планируемая работа на занятии

1. Разобрать запрос, ответ, метод, маршрут, заголовки и коды состояния.
2. Создать сервер net/http с маршрутом проверки состояния.
3. Вернуть список задач в JSON и принять простое создание задачи.
4. Проверить маршруты HTTP-клиентом. Общую изменяемую память нельзя оставлять без защиты при конкурентных запросах.

## Ожидаемый результат

Первые HTTP-маршруты и JSON-ответы.

## Самостоятельная часть и расширение

Закрепить методы и статусы, описать запросы и ответы. Постоянное хранилище подключается отдельно.
