## Цель

Познакомиться с конкурентным выполнением и подготовить воспроизводимую демонстрацию проекта.

## Планируемая работа на занятии

1. На отдельном небольшом примере обработать ограниченный набор задач через goroutine и channel.
2. Собрать результаты и дождаться завершения; не использовать time.Sleep вместо синхронизации.
3. Разобрать контроль завершения фоновых операций и доступа к общим данным.
4. Проверить итоговый API, показать структуру кода, ошибки и тесты. Основной проект готовится на предыдущих занятиях и самостоятельно.

## Ожидаемый результат

Учебный пример конкурентности и демонстрация итогового бэкенда.

## Самостоятельная часть и расширение

Завершить README и описать ограничения. Встраивание фонового обработчика в API — дополнительное задание.
