## Цель

Объединить HTTP API и PostgreSQL в работающий сервис.

## Планируемая работа на занятии

1. Подключить к обработчикам ранее разработанные операции GORM.
2. Реализовать создание, список, поиск по ID, изменение и удаление задач.
3. Связать задачи с проектами и обрабатывать ошибки без выдачи клиенту внутренних сведений подключения.
4. Проверить сквозной сценарий CRUD и сохранность данных после перезапуска.

## Ожидаемый результат

API управления задачами с постоянным хранением данных.
