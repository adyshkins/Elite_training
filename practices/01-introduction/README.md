## 1. Инструменты и подготовка

**Go** — язык, на котором записывается программа. **Go SDK** содержит инструменты сборки и стандартную библиотеку. **Редактор или IDE** помогает писать код. **Терминал** позволяет запускать команды и видеть результат.

| Вариант | Как используем |
|---|---|
| VS Code + расширение Go | Основной вариант для инструкций курса |
| GoLand | Альтернатива, если эта среда уже доступна и удобна |
| Текстовый редактор + терминал | Достаточно для простых программ |
| Go Playground | Временный вариант в браузере без локальной сборки |

Установите Go и **один** редактор по [инструкции настройки](../../docs/environment.md). Там описаны Windows, macOS и Linux, настройка VS Code и GoLand. Git и PostgreSQL пока не нужны.

Проверьте в терминале:

```bash
go version
```

В выводе должны быть номер версии и платформа. Если команда не найдена, сначала исправьте установку. Одно расширение VS Code не заменяет компилятор Go.

## 2. Первая программа

### Шаг 1. Создайте папку и модуль

В терминале перейдите в доступную папку для учебных проектов, затем выполните:

```bash
mkdir go-practice-01
cd go-practice-01
go mod init example.com/go-practice-01
```

Откройте папку `go-practice-01` в редакторе. В ней появится `go.mod`: файл описания модуля. Модуль объединяет код проекта; подробнее мы разберём это позже.

`example.com/go-practice-01` — учебное имя. Регистрировать домен или создавать сайт не нужно. Если редактор уже создал `go.mod`, повторять `go mod init` не требуется.

### Шаг 2. Создайте `main.go`

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет! Это моя первая программа на Go.")
}
```

Сохраните файл рядом с `go.mod`. Проверьте, что он называется `main.go`, а не `main.go.txt`.

| Конструкция | Значение |
|---|---|
| `package main` | Пакет исполняемой программы |
| `import "fmt"` | Подключение пакета форматированного ввода и вывода |
| `func main()` | Точка начала выполнения нашего приложения |
| `{ ... }` | Блок кода функции |
| `fmt.Println(...)` | Вывод текста с переводом строки |

`fmt` входит в стандартную библиотеку — скачивать его отдельно не нужно.

### Шаг 3. Запустите программу

Из папки с `go.mod`:

```bash
go run .
```

Ожидаемый вывод:

```text
Привет! Это моя первая программа на Go.
```

Точка означает текущий пакет. Для одного файла также сработает `go run main.go`, но при появлении нескольких файлов удобнее запускать пакет целиком.

Измените сообщение, сохраните файл и повторите запуск. Вывод должен измениться.

### Шаг 4. Соберите исполняемый файл

**Windows / PowerShell:**

```powershell
go build -o hello.exe .
.\hello.exe
```

**macOS / Linux:**

```bash
go build -o hello .
./hello
```

`go run` собирает и сразу запускает программу. `go build` создаёт результат сборки, который запускается отдельной командой. Для запуска этой собранной программы редактор не нужен.

> После изменения `main.go` уже собранный файл не обновляется автоматически. Старый `hello` или `hello.exe` продолжит выводить прежний текст, пока вы снова не выполните `go build`.

### Шаг 5. Отформатируйте код

```bash
go fmt ./...
```

Команда форматирует Go-код в пакетах текущего модуля. Пустой вывод нормален, если менять нечего.

Шаги этого раздела — **обязательное задание 1**. Подробности команд: [справочник go](https://pkg.go.dev/cmd/go), [официальное начало работы](https://go.dev/doc/tutorial/getting-started).

## 3. Основы синтаксиса

Разбирайте фрагменты внутри `main`, заменяя предыдущий эксперимент. Не создавайте несколько функций `main` в одной папке. Полные запускаемые примеры находятся в [examples](examples/README.md).

### Переменные: `var`, `:=` и `=`

```go
var language string = "Go"
var completed int = 2
name := "Учебный проект"

completed = 3
fmt.Println(language, name, completed)
```

`var` объявляет переменную. При наличии значения тип можно не писать: `var completed = 2`.

`:=` — краткое объявление внутри функции: тип определяется по значению. `=` присваивает новое значение уже объявленной переменной. Повторное `completed := 3` в том же блоке не подойдёт: новой переменной здесь нет.

Имена чувствительны к регистру: `name` и `Name` различаются. Выбирайте понятные названия: например, `totalMinutes` для количества минут.

Источники: [переменные](https://go.dev/tour/basics/8), [краткое объявление](https://go.dev/tour/basics/10).

### Базовые типы и нулевые значения

| Тип | Для чего | Пример | Значение без инициализации |
|---|---|---|---|
| `int` | Целые числа | `12` | `0` |
| `float64` | Числа с дробной частью | `3.5` | `0` |
| `bool` | Логические значения | `true` | `false` |
| `string` | Строки | `"Go"` | `""` |

```go
var count int
var ready bool
var title string
fmt.Printf("count=%d, ready=%t, title=%q\n", count, ready, title)
```

Вывод:

```text
count=0, ready=false, title=""
```

Дробную часть в коде записывают через точку: `3.5`, а не `3,5`.

Источники: [базовые типы](https://go.dev/tour/basics/11), [нулевые значения](https://go.dev/tour/basics/12).

### Константы и комментарии

```go
const courseName = "Бэкенд-разработка на языке Go"

// Комментарий объясняет следующую строку.
fmt.Println(courseName)
```

`const` задаёт константу: присвоить ей новое значение нельзя. Для изменяющихся данных используйте переменные.

Источник: [константы](https://go.dev/tour/basics/15).

### Арифметика и преобразования

```go
a := 17
b := 5
fmt.Println(a + b)                  // 22
fmt.Println(a - b)                  // 12
fmt.Println(a * b)                  // 85
fmt.Println(a / b)                  // 3
fmt.Println(a % b)                  // 2
fmt.Println(float64(a) / float64(b)) // 3.4
```

При делении целых чисел дробная часть отбрасывается. `%` — остаток от целочисленного деления. Для дробного результата преобразуйте операнды **до** деления: `float64(a / b)` преобразует уже усечённое значение.

В этой работе делитель известен и не равен нулю. Проверку произвольного пользовательского делителя разберём после знакомства с условиями.

Источники: [преобразование типов](https://go.dev/tour/basics/13), [арифметические операции](https://go.dev/ref/spec#Arithmetic_operators).

### Вывод данных

```go
name := "Ирина"
lessons := 12
progress := 8.25
fmt.Print("Участник: ")
fmt.Println(name)
fmt.Printf("Занятий: %d\n", lessons)
fmt.Printf("Прогресс: %.1f\n", progress)
```

`Print` не добавляет перевод строки, `Println` добавляет. `Printf` использует строку формата: `%s` — строка, `%d` — целое, `%t` — логическое значение, `%.2f` — дробное число с двумя знаками после точки, `%T` — тип значения, `%q` — строка в кавычках. `\n` обозначает перевод строки.

Формат должен соответствовать типу значения: для `int` используйте `%d`, для `float64` — `%f` или вариант с точностью.

Источник: [fmt](https://pkg.go.dev/fmt).

## 4. Ввод данных

Для первой работы достаточно чтения одного целого числа из терминала:

```go
var pages int
fmt.Print("Введите число страниц: ")
_, err := fmt.Scan(&pages)
if err != nil {
    fmt.Println("Ошибка: нужно ввести целое число.")
    return
}
if pages < 0 {
    fmt.Println("Ошибка: число не должно быть отрицательным.")
    return
}
fmt.Printf("Будет обработано страниц: %d\n", pages)
```

Полный пример — [examples/input/main.go](examples/input/main.go). Введите число в терминале и нажмите Enter. Ожидание ввода не означает, что программа зависла.

Некоторые конструкции изучим позже. Сейчас используйте их как готовый образец проверяемого ввода:

| Конструкция | Что нужно понять сейчас |
|---|---|
| `&pages` | Позволяет записать ввод в переменную; указатели подробно разберём в ПР № 3 |
| `_, err := ...` | Получаем ошибку чтения; первое возвращаемое значение сейчас не используем |
| `if err != nil` | При ошибке чтения выводим сообщение |
| `if pages < 0` | Отбрасываем недопустимое по смыслу значение |
| `return` | Завершаем `main`, не выполняя дальнейшие вычисления |

Не удаляйте проверки ошибок ради сокращения примера. Условия подробно разберём на следующем занятии, ошибки — в отдельной теме. Повторный запрос в цикле пока не требуется: после ошибки запустите программу заново.

Допустимый ввод — одно целое число. Проверку лишних слов после числа на этом занятии не требуем.

Источник: [fmt.Scan](https://pkg.go.dev/fmt#Scan).

### Задание 1. Первая программа — обязательное, вместе с преподавателем

### Задание 2. Карточка участника курса — обязательное

Напишите программу вывода карточки. Используйте вымышленное имя — публиковать персональные данные не нужно.

Название курса храните в константе. Для имени и группы используйте строки, для количества завершённых работ — целое число, для интереса к серверной разработке — логическое значение. Примените объявление через `var` и через `:=`.

Выводите данные из переменных, а не одной заранее подготовленной строкой. Используйте `fmt.Println` и хотя бы один `fmt.Printf`. Ввод с клавиатуры не требуется.

Пример:

```text

Группа: Учебная-01
Курс: Бэкенд-разработка на языке Go
Завершено работ: 1

```

Запуск из `practice-01-solutions`:

```bash
go run ./cmd/card
```

**Проверка:** измените имя и число завершённых работ в коде; повторный запуск должен показать новые значения. Все локальные переменные должны использоваться.

### Задание 3. Перевод минут в часы — обязательное

Прочитайте одно целое неотрицательное число минут. Выведите число полных часов и оставшихся минут.

```text
Введите количество минут: 125
Полных часов: 2
Оставшихся минут: 5
```

Используйте константу для числа минут в часе, операции `/` и `%`, форматированный вывод. Готовые функции работы с датой и временем не нужны.

Для чтения возьмите образец из раздела 4 или готовый блок в `starter`. При вводе текста вместо числа или отрицательного значения выведите понятное сообщение и завершитесь без расчёта.

```bash
go run ./cmd/time-converter
```

**Проверьте все наборы данных:**

| Ввод | Полных часов | Оставшихся минут | Поведение |
|---:|---:|---:|---|
| `0` | 0 | 0 | Корректный результат |
| `59` | 0 | 59 | Корректный результат |
| `60` | 1 | 0 | Корректный результат |
| `125` | 2 | 5 | Корректный результат |
| `1500` | 25 | 0 | Часы не обнуляются после 24 |
| `-1` | — | — | Сообщение о недопустимом отрицательном значении |
| `abc` | — | — | Сообщение об ошибке чтения числа |

Не подставляйте ответы вручную: программа должна рассчитывать результат и для других допустимых значений.

### Задание 4. Среднее время решения — дополнительное

Даны три целых значения времени решения задач: 20, 25 и 35 минут. Запишите их в переменные, вычислите сумму и среднее арифметическое. Выведите среднее с двумя знаками после точки.

Ожидаемый результат: сумма — `80`, среднее — `26.67`. Преобразуйте значение в `float64` **до** деления. Для данных `1`, `1`, `2` среднее должно выводиться как `1.33`.

Создайте `cmd/average/main.go` в том же модуле. Это упражнение выполняется после обязательной части.

## 6. Частые ошибки

| Симптом | Что проверить |
|---|---|
| `go` не найден | Установлен ли SDK; перезапущен ли терминал; корректен ли `PATH` |
| `go.mod file not found` | Текущую папку и наличие `go.mod` |
| `go.mod already exists` | Модуль уже создан; второй `go mod init` не нужен |
| `no Go files` | Есть ли сохранённые `.go`-файлы; не нужно ли запускать `go run ./cmd/card` |
| `main redeclared` | Несколько программ находятся в одной папке; разнесите их по каталогам |
| `declared and not used` | Неиспользуемую локальную переменную |
| `imported and not used` | Импорт пакета, который не используется |
| `no new variables on left side of :=` | Не нужно ли присваивание через `=` вместо повторного объявления |
| `cannot use ... as ...` | Соответствие типов и необходимость явного преобразования |
| Вывод содержит `%!` | Соответствие спецификатора `Printf` типу значения |
| Программа ждёт | Не ожидает ли `fmt.Scan` ввод в терминале |
| Запускается старый вариант | Сохранён ли исходник и выполнена ли повторная сборка |

Сначала найдите имя файла, номер строки и сообщение компилятора. Не исправляйте ошибки случайным удалением строк.
