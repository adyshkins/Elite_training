# Самостоятельные задания первой практики

[К пошаговой инструкции](README.md) · [Справочник синтаксиса и ввода](syntax-and-input.md)

## Где выполнять задания

Продолжаем **свой существующий проект `go-practice-01`**. Первая программа остаётся в корневом `main.go`. Карточка и конвертер будут в разных подпапках `cmd` и используют тот же `go.mod`.

Ожидаемая структура после обязательных заданий:

```text
go-practice-01/
├── .gitignore
├── README.md
├── go.mod
├── main.go
└── cmd/
    ├── experiments/
    │   └── main.go
    ├── card/
    │   └── main.go
    └── time-converter/
        └── main.go
```

`.gitignore` и README добавляются при прохождении раздела Git. Если вы ещё не дошли до публикации, их отсутствие на этапе карточки нормально.

**Все команды ниже вводятся в терминале из корня `go-practice-01`, не из папки отдельной задачи.** Проверяйте путь командой `pwd`. Не создавайте ещё один модуль внутри `cmd` и не помещайте две функции `main` в одну папку.

### Как добавить папку новой программы

1. В VS Code откройте слева **Explorer / Проводник**. Папка `cmd` уже создана в разделе о синтаксисе. Если её нет, создайте её через правую кнопку по `GO-PRACTICE-01` → **New Folder**.
2. Нажмите правой кнопкой по `cmd` → **New Folder** и введите имя из задания, например `card`.
3. Нажмите правой кнопкой по новой папке → **New File**, создайте `main.go`.
4. Вставьте полный каркас ниже и сохраните файл. Он пока только сообщает, что решение предстоит написать.

**Каркас отдельной программы:**

```go
package main

import "fmt"

func main() {
	fmt.Println("Здесь будет решение задания.")
}
```

Код решения нужно написать внутри функции вместо строки-подсказки. Более подробные заготовки: [карточка](starter/cmd/card/main.go) и [конвертер](starter/cmd/time-converter/main.go). Открывайте ссылку, копируйте **всё содержимое одного файла**, вставляйте в соответствующий свой `main.go` и сохраняйте.

Скачивать весь курс и копировать его `go.mod` для этого пути не нужно. Старый способ работы с отдельной копией папки `starter` сохранён как [альтернативный вариант](starter/README.md), а не второй обязательный проект.

## Задание 1. Первая программа

**Выполняется вместе с преподавателем, обязательное.** Пройдите разделы 2–4 [основной инструкции](README.md).

Нужно изменить приветствие, сохранить код, запустить через `go run .`, собрать исполняемый файл и запустить его отдельной командой. Покажите, почему уже собранный файл выводит прежний текст, если код изменён, а повторная сборка не выполнена.

**Результат:** `main.go` и `go.mod` в своей папке. Исполняемый файл можно оставить локально для демонстрации, но в Git и сдаваемый архив его не добавляют.

## Задание 2. Карточка участника курса

**Обязательное, основной маршрут первой пары.** Создайте **`cmd/card/main.go`** способом, описанным выше.

Программа выводит карточку участника. Используйте вымышленное имя: публиковать реальные персональные данные не нужно.

Название курса храните в **константе**. Для имени и группы используйте строки, для количества завершённых работ — целое число, для интереса к серверной разработке — логическое значение. Примените объявление и через `var`, и через `:=`.

Выводите значения переменных, а не одну заранее подготовленную строку. Используйте `fmt.Println` и хотя бы один `fmt.Printf`. Ввод с клавиатуры здесь **не требуется**.

**Пример результата:**

```text
Участник: Алексей
Группа: Учебная-01
Курс: Бэкенд-разработка на языке Go
Завершено работ: 1
Интерес к бэкенду: true
```

**Запуск из корня проекта:**

```text
go run ./cmd/card
```

**Проверка:** измените вымышленное имя и число завершённых работ, сохраните и снова запустите. Значения в выводе должны измениться. Все объявленные локальные переменные должны использоваться. Объясните, что хранится в каждой переменной и чем константа отличается от неё.

После карточки перейдите к [публикации проекта](../../docs/first-project-github.md), затем продолжите закрепление ниже.

## Задание 3. Перевод минут в часы

**Обязательное закрепление; можно завершить после пары.** Создайте **`cmd/time-converter/main.go`**.

Прочитайте одно целое неотрицательное число минут и выведите полные часы и оставшиеся минуты.

**Пример работы; `125` вводит пользователь:**

```text
Введите количество минут: 125
Полных часов: 2
Оставшихся минут: 5
```

Используйте константу для числа минут в часе, операции `/` и `%`, форматированный вывод. Готовые функции работы с датой и временем не нужны.

Для чтения используйте [разобранный образец](syntax-and-input.md#4-ввод-числа-и-проверки) или скопируйте **весь код [заготовки конвертера](starter/cmd/time-converter/main.go)**. В заготовке ввод и проверки уже есть, а вычисления и вывод результата нужно дописать самостоятельно. Не удаляйте проверки.

При вводе текста вместо числа или отрицательного числа программа должна вывести понятное сообщение и завершиться **без расчёта**. Повторный ввод в цикле не требуется.

**Запуск из корня проекта:**

```text
go run ./cmd/time-converter
```

После запуска щёлкните в терминале, введите одно значение и нажмите Enter. Для каждого следующего значения снова запускайте программу той же командой.

**Проверьте все семь наборов:**

| Ввод | Полных часов | Оставшихся минут | Поведение |
|---:|---:|---:|---|
| `0` | 0 | 0 | Корректный результат |
| `59` | 0 | 59 | Корректный результат |
| `60` | 1 | 0 | Корректный результат |
| `125` | 2 | 5 | Корректный результат |
| `1500` | 25 | 0 | Часы не обнуляются после 24 |
| `-1` | — | — | Сообщение о недопустимом отрицательном значении |
| `abc` | — | — | Сообщение об ошибке чтения числа |

Не подставляйте ответы вручную: программа должна вычислять результат и для других допустимых значений. Запишите фактические результаты проверок в README.

## Дополнительное задание. Среднее время решения

Выполняется **после обязательной части**. Создайте `cmd/average/main.go` тем же способом, что и другие программы.

Даны три целых значения времени: `20`, `25` и `35` минут. Запишите их в переменные, найдите сумму и среднее арифметическое, выведите среднее с двумя знаками после точки.

Ожидаемый результат: сумма `80`, среднее `26.67`. Преобразуйте значение в `float64` **до** деления. На данных `1`, `1`, `2` среднее должно выводиться как `1.33`.

**Запуск из корня проекта:**

```text
go run ./cmd/average
```
