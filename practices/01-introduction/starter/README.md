# Стартовый проект для заданий 2–3

[Полное условие первой практики](../README.md)

Это **заготовки, а не готовые решения**. Ввод и его проверка в конвертере уже написаны. Вычисления, вывод результата и код карточки нужно дополнить самостоятельно.

Скопируйте **всю папку starter** за пределы учебного репозитория, переименуйте в practice-01-solutions и откройте её в редакторе. Файл go.mod уже существует; повторный go mod init не нужен.

```text
practice-01-solutions/
├── go.mod
├── README.md
└── cmd/
    ├── card/main.go
    └── time-converter/main.go
```

Команды выполняются из practice-01-solutions:

```bash
go run ./cmd/card
go run ./cmd/time-converter
go fmt ./...
go build ./...
```

Первоначальный вывод содержит подсказки, а не решение задания.

Замените этот README описанием своей работы: версия Go, команды запуска, выполненные пункты и проверки. Не удаляйте go.mod, не помещайте две функции main в одну папку и не добавляйте исполняемые файлы в архив.

Для дополнительного задания можно создать cmd/average/main.go в том же модуле.
