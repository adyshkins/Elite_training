# Заготовки карточки и конвертера

[К первой практике](../README.md) · [Условия заданий](../assignments.md)

Это **заготовки, а не готовые решения**. В конвертере уже написаны ввод и его проверка. Вычисления, вывод результата и код карточки нужно дописать самостоятельно. Первоначальный вывод содержит подсказки, а не ответы задачи.

## Основной путь: использовать свой проект

Не создавайте второй проект, если уже работаете в `go-practice-01`.

1. По [инструкции создания папок](../assignments.md#как-добавить-папку-новой-программы) создайте в своём проекте `cmd/card/main.go` и `cmd/time-converter/main.go`.
2. Откройте на сайте [заготовку карточки](cmd/card/main.go), скопируйте **весь текст файла** в свой `cmd/card/main.go`, сохраните.
3. Откройте [заготовку конвертера](cmd/time-converter/main.go), скопируйте весь текст в свой `cmd/time-converter/main.go`, сохраните.
4. **Не копируйте `go.mod` из `starter`:** он нужен только альтернативному варианту ниже. У вашего проекта уже есть свой модуль.
5. В терминале из корня `go-practice-01` выполните по очереди:

```text
go run ./cmd/card
go run ./cmd/time-converter
```

Для конвертера введите число и нажмите Enter. Убедитесь, что заготовки запускаются; затем допишите решение по [условиям](../assignments.md).

## Альтернатива: отдельная копия всего starter

Этот способ сохранён для работы с готовым самостоятельным модулем, например при восстановлении пропущенного занятия. **Не нужно проходить оба пути.**

1. [Скачайте и распакуйте курс](../../../docs/how-to-use.md#4-как-скачать-все-примеры-без-git).
2. В файловом менеджере найдите `practices/01-introduction/starter` в распакованной папке.
3. **Скопируйте**, не перемещайте, всю папку `starter` в свою `GoProjects`. Назовите копию **`practice-01-solutions`**. Существующую папку с работой не заменяйте.
4. В VS Code через **File → Open Folder** откройте копию `practice-01-solutions`.
5. Здесь уже есть `go.mod`; команду `go mod init` **не выполняйте**.

```text
practice-01-solutions/
├── go.mod
├── README.md
└── cmd/
    ├── card/main.go
    └── time-converter/main.go
```

Откройте новый терминал VS Code и убедитесь через `pwd`, что он находится в `practice-01-solutions`. Тогда команды будут такими:

```text
go run ./cmd/card
go run ./cmd/time-converter
go fmt ./...
go build ./...
```

В этой альтернативной папке нет корневого `main.go`, поэтому `go run .` для неё не подходит: указывайте `./cmd/card` или `./cmd/time-converter`.

Замените README копии описанием своей работы: версия Go, команды, выполненные пункты и проверки. Первую программу из основного занятия при этом не удаляйте; она остаётся в `go-practice-01` и тоже должна быть показана преподавателю. Для первой публикации предпочтителен основной путь с одним проектом.

Для дополнительного задания создайте `cmd/average/main.go`. Не помещайте две функции `main` в одну папку, не удаляйте `go.mod` и не отправляйте исполняемые файлы.
