# Синтаксис, арифметика и ввод: справочник первой практики

[К первой практике](README.md) · [К заданиям](assignments.md)

Работайте в **`cmd/experiments/main.go`** своего проекта, созданном в разделе 5 первой практики. Не заменяйте первую программу в корневом `main.go`.

Ниже явно разделены **полные программы** и **фрагменты**. Фрагмент вставляют **внутрь существующих `{ ... }` функции `main`**, вместо предыдущего эксперимента. Он не заменяет `package main`, `import` и объявление функции. Не вставляйте сразу все примеры друг за другом: имена переменных могут повторяться.

Перед каждым запуском сохраняйте файл. **Команда из корня `go-practice-01`:**

```text
go run ./cmd/experiments
```

## 1. Переменные, константы и типы

### Объявление и изменение

**Фрагмент внутри `main`:**

```go
var language string = "Go"
var completed int = 2
name := "Учебный проект"

completed = 3
fmt.Println(language, name, completed)
```

Ожидаемый вывод: `Go Учебный проект 3`.

`var` объявляет переменную. При наличии значения тип можно не писать: `var completed = 2`. `:=` — краткое объявление внутри функции; тип определяется по значению. `=` меняет значение уже объявленной переменной.

Повторное `completed := 3` в том же блоке здесь будет ошибкой: новой переменной нет. Имена чувствительны к регистру: `name` и `Name` различаются. Для числа минут понятнее имя `totalMinutes`, чем `x`.

[Переменные](https://go.dev/tour/basics/8) · [Краткое объявление](https://go.dev/tour/basics/10).

### Базовые типы и нулевые значения

| Тип | Что хранит | Пример | Значение без инициализации |
|---|---|---|---|
| `int` | Целое число | `12` | `0` |
| `float64` | Дробное число | `3.5` | `0` |
| `bool` | Логическое значение | `true` | `false` |
| `string` | Строку | `"Go"` | `""` — пустую строку |

**Фрагмент внутри `main`:**

```go
var count int
var ready bool
var title string
fmt.Printf("count=%d, ready=%t, title=%q\n", count, ready, title)
```

**Ожидаемый вывод:**

```text
count=0, ready=false, title=""
```

Нулевое значение — то, что получает объявленная переменная, когда начальное значение не задано. Дробную часть в коде записывают через точку: `3.5`, не `3,5`.

[Базовые типы](https://go.dev/tour/basics/11) · [Нулевые значения](https://go.dev/tour/basics/12).

### Константы и комментарии

**Фрагмент внутри `main`:**

```go
const courseName = "Бэкенд-разработка на языке Go"

// Комментарий объясняет следующую строку.
fmt.Println(courseName)
```

`const` задаёт константу. Далее присвоить ей новое значение нельзя; для изменяющихся данных нужны переменные. После `//` до конца строки записывается комментарий, не выполняемая команда.

[Константы](https://go.dev/tour/basics/15).

## 2. Арифметика и преобразование типов

**Фрагмент внутри `main`:**

```go
a := 17
b := 5
fmt.Println(a + b)                  // 22
fmt.Println(a - b)                  // 12
fmt.Println(a * b)                  // 85
fmt.Println(a / b)                  // 3
fmt.Println(a % b)                  // 2
fmt.Println(float64(a) / float64(b)) // 3.4
```

Комментарии справа показывают ожидаемые результаты. При делении целых чисел дробная часть отбрасывается. `%` — остаток от целочисленного деления. Для дробного результата преобразуйте числа **до** деления: `float64(a / b)` превратит уже полученную целую тройку в дробный тип, но потерянную часть не вернёт.

В примере делитель известен и не равен нулю. Проверку произвольного пользовательского делителя будем рассматривать после знакомства с условиями.

**Проверьте:** замените числа на `10` и `4`, запустите программу и объясните отличие результатов целого и дробного деления.

[Преобразования](https://go.dev/tour/basics/13) · [Арифметические операции](https://go.dev/ref/spec#Arithmetic_operators).

## 3. Вывод данных

**Фрагмент внутри `main`:**

```go
name := "Ирина"
lessons := 12
progress := 8.25
fmt.Print("Участник: ")
fmt.Println(name)
fmt.Printf("Занятий: %d\n", lessons)
fmt.Printf("Прогресс: %.1f\n", progress)
```

`Print` не добавляет перевод строки, `Println` добавляет. `Printf` использует строку формата. Для `progress` вывод с одним знаком после точки будет `8.2`.

| Формат | Что выводит |
|---|---|
| `%s` | Строку |
| `%d` | Целое число |
| `%t` | Логическое значение |
| `%f`, `%.2f` | Дробное число; во втором случае — два знака после точки |
| `%T` | Тип значения |
| `%q` | Строку в кавычках |
| `\n` | Перевод строки |

Формат должен соответствовать типу: для `int` нужен `%d`, для `float64` — `%f` или вариант с точностью. Подробности: [пакет `fmt`](https://pkg.go.dev/fmt).

## 4. Ввод числа и проверки

После вывода заранее заданных значений можно получить число от пользователя. Здесь встречаются конструкции будущих тем. **Сейчас разрешено использовать блок ввода как образец**, понимая назначение каждой проверки; циклы и сложную обработку ошибок писать не требуется.

**Полная программа для `cmd/experiments/main.go`:**

```go
package main

import "fmt"

func main() {
	var pages int
	fmt.Print("Введите число страниц: ")
	_, err := fmt.Scan(&pages)
	if err != nil {
		fmt.Println("Ошибка: нужно ввести целое число.")
		return
	}
	if pages < 0 {
		fmt.Println("Ошибка: число не должно быть отрицательным.")
		return
	}
	fmt.Printf("Будет обработано страниц: %d\n", pages)
}
```

Сохраните файл и выполните `go run ./cmd/experiments` из корня проекта. Когда появится приглашение, **введите `12` в том же терминале и нажмите Enter**. Число не нужно писать в исходном коде и не нужно вводить отдельную команду Go.

**Пример работы; `12` вводит пользователь:**

```text
Введите число страниц: 12
Будет обработано страниц: 12
```

Если программа ждёт ввод, она не обязательно зависла. Для принудительной остановки текущего запуска можно нажать **Ctrl+C** в терминале.

| Конструкция | Что означает в примере |
|---|---|
| `&pages` | Передаёт возможность записать прочитанное в переменную; указатели разберём в ПР № 3 |
| `_, err := ...` | Получаем ошибку чтения; число успешно прочитанных значений здесь не используем |
| `if err != nil` | Если чтение не удалось, выполняем блок сообщения об ошибке |
| `if pages < 0` | Отбрасываем отрицательное число, недопустимое по условию |
| `return` | Выходим из `main`, не выполняя дальнейший расчёт |

Проверки не удаляем ради короткого примера. После ошибки программу запускают заново: повторный запрос в цикле пока не требуется.

**Проверьте каждый ввод отдельным запуском:**

| Ввод | Результат |
|---|---|
| `12` | Вывод числа страниц 12 |
| `0` | Вывод числа страниц 0 |
| `-1` | Сообщение об отрицательном значении, без результата обработки |
| `abc` | Сообщение об ошибке чтения, без результата обработки |

Допустимый формат — одно целое число. Проверку лишних слов после числа в первой работе не требуем. Полный исходный пример для сверки — [файл `examples/input/main.go`](examples/input/main.go). Источник: [`fmt.Scan`](https://pkg.go.dev/fmt#Scan).
