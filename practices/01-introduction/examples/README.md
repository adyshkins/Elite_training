# Примеры первой практики

[К заданию](../README.md)

Примеры используют только стандартную библиотеку. Это материал для разбора, а не готовые решения самостоятельных заданий.

Откройте **эту папку examples**, содержащую `go.mod`, в редакторе или терминале. Из корня курса путь к ней: `practices/01-introduction/examples`.

| Папка | Что показывает | Команда из examples |
|---|---|---|
| hello | Структуру программы и вывод | `go run ./hello` |
| variables | Переменные, константы, нулевые значения, деление и форматирование | `go run ./variables` |
| input | Ввод целого числа и проверку ошибок | `go run ./input` |

Для input введите `12`, затем отдельно проверьте `0`, `-1` и `abc`. При неверном вводе программа сообщает об ошибке и завершается; цикл повторного запроса пока не реализуется.

Каждая папка содержит самостоятельную программу. Не объединяйте их main.go в один каталог.

## Проверка сборки

```bash
go fmt ./...
go build ./...
go vet ./...
```

Это проверка кода примеров. Написание модульных тестов изучается позже.

В go.mod указан минимальный уровень языка для этих примеров, а не рекомендация устанавливать старый выпуск Go. Используйте актуальный стабильный SDK с [официального сайта](https://go.dev/dl/).
