# Готовые примеры первой практики

[К первой практике](../README.md) · [Как получить файлы](../../../docs/how-to-use.md)

Это примеры для разбора, а не готовые решения самостоятельных заданий. Они используют только стандартную библиотеку Go.

## Сначала выберите способ работы

**Только посмотреть код:** откройте ссылку на нужный `main.go` в таблице ниже. Скачивание и Git не нужны.

**Запустить готовые файлы:** сначала установите Go и VS Code по [инструкции](../../../docs/environment.md). Затем [скачайте и распакуйте ZIP курса](../../../docs/how-to-use.md#4-как-скачать-все-примеры-без-git).

В VS Code выберите **File → Open Folder** и найдите внутри распакованного курса папку:

```text
practices/01-introduction/examples
```

Откройте **именно `examples`**. В ней уже есть `go.mod` и папки `hello`, `variables`, `input`. Не открывайте отдельный файл вместо папки и не выполняйте `go mod init`: модуль подготовлен.

Откройте **Terminal → New Terminal**. Выполните `pwd` и `ls`: путь должен заканчиваться на `examples`, а список — содержать `go.mod`.

## Запуск

Вводите в терминале **одну команду за раз** и нажимайте Enter.

| Файл | Что показывает | Команда из `examples` |
|---|---|---|
| [hello/main.go](hello/main.go) | Структуру программы и вывод | `go run ./hello` |
| [variables/main.go](variables/main.go) | Переменные, константы, нулевые значения, деление и форматирование | `go run ./variables` |
| [input/main.go](input/main.go) | Ввод целого числа и проверку ошибок | `go run ./input` |

Для третьего примера после запуска введите **`12`** в том же терминале и нажмите Enter. Затем отдельными запусками проверьте `0`, `-1` и `abc`. При неверном вводе программа сообщает об ошибке и завершается; повторного запроса в цикле пока нет.

Каждая подпапка содержит отдельную программу. Не объединяйте все `main.go` в один каталог.

## Проверка сборки

Из той же папки `examples`:

```text
go fmt ./...
go build ./...
go vet ./...
```

`go build` проверяет сборку, `go vet` дополнительно ищет некоторые типичные ошибки. Написание тестов изучается позднее.

В `go.mod` указан минимальный уровень для модуля, а не рекомендация устанавливать старый выпуск. Используйте актуальный стабильный SDK с [официального сайта](https://go.dev/dl/).

**Чтобы вернуться к своему проекту**, снова выберите **File → Open Folder → GoProjects/go-practice-01** и создайте новый терминал. Смена папки в редакторе и открытая вкладка исходного файла — не одно и то же.
