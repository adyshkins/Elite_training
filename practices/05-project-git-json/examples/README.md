# Работающий пример для ПР № 5

[← Методичка](../README.md) · [Стартовый проект](../starter/README.md)

Это **отдельный демонстрационный Go-модуль** `example.com/go-practice-01`, не исходный код для сдачи. Использует только стандартную библиотеку. Программу следует запускать **из папки `examples/`**:

~~~bash
go run ./cmd/task-cli-json
go test ./...
go vet ./...
go build ./...
~~~

Ввод для проверки: `1` → название → приоритет → `2` → `0`; затем откройте программу повторно и проверьте сохранение. В папке `examples/` появится `tasks.json` — это локальные учебные данные; не добавляйте файл в коммит. Его можно удалить после эксперимента.

**Состав:**
- `cmd/task-cli-json/main.go` — консольное меню, валидация ввода, вызовы сохранения.
- `internal/tasks/store.go` — модель, CRUD, снимок состояния, проверка при восстановлении.
- `internal/persistence/json.go` — чтение/запись JSON с проверкой ошибок.
- `internal/persistence/json_test.go` — тесты успешной загрузки, неверного JSON, пустого/отсутствующего файла и продолжения ID.

В **личном проекте** не копируйте файл `examples/go.mod` поверх своего. Переносите структуру папок `starter/`, а не готовое решение.

**Важное ограничение:** файл JSON не подходит для конкурентного изменения несколькими процессами. Перенос хранения в PostgreSQL начнётся с [ПР № 6](../../06-postgresql-sql/README.md).
