## Цель

Организовать код и обеспечить сохранность данных между запусками.

## Планируемая работа на занятии

1. Разделить готовое приложение по пакетам; разобрать go.mod и одну настройку через переменную окружения.
2. Добавить сохранение и загрузку JSON, проверить отсутствие файла и некорректный JSON.
3. Продолжить работу с существующим Git-репозиторием: проверить историю, уточнить .gitignore и README, сохранить отдельный коммит с новым этапом приложения. Создание репозитория и первая публикация уже разобраны в ПР № 1.
4. Разобрать один табличный тест. Использовать заранее подготовленный каркас вместо переписывания приложения.

## Ожидаемый результат

Организованный проект с файловым хранением, историей изменений и первым тестом.

## Самостоятельная часть и расширение

Расширить тесты и README. Ветки и простой конфликт разобрать как самостоятельный сценарий по отдельной инструкции. Первую настройку Git повторять только при необходимости; [инструкция для восстановления навыка](../../docs/first-project-github.md).
