# Стартовый каркас ПР № 5

[← Методичка](../README.md) · [Условия](../assignments.md)

Скопируйте папки **`cmd/` и `internal/`** отсюда в **корень вашего существующего `go-practice-01`**. Не удаляйте файлы ПР № 1–4 и не копируйте новый `go.mod`: у вас уже есть модуль.

- `internal/tasks/store.go`: готовая модель и CRUD из ПР № 4, с добавленными `Snapshot` и `Restore`. Изучите его, затем используйте в новой программе.
- `cmd/task-cli-json/main.go`: готовый каркас интерфейса ввода, создающий `TASKS_FILE` и вызывающий функции хранения.
- `internal/persistence/json.go`: **две заглушки TODO**. Именно их требуется реализовать на занятии.
- `internal/persistence/json_test.go`: проверочные тесты, которые до реализации будут **падать**.

**Проверьте импорт:** каркас предполагает `module example.com/go-practice-01`. Если в вашем `go.mod` другое имя, исправьте префиксы в трёх Go-файлах `cmd/task-cli-json/main.go`, `internal/persistence/json.go`, `internal/persistence/json_test.go`.

Начните с команды `go run ./cmd/task-cli-json` из корня **личного проекта**. Заглушка позволит добавить задачу, но после выхода она исчезнет. Цель работы — добиться настоящего сохранения и прохождения `go test ./...`.

Не копируйте папку `starter` целиком как вложенный модуль в `go-practice-01`: в таком случае `go run ./cmd/task-cli-json` не увидит команду.
