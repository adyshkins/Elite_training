# Задания практической работы № 4

[Пошаговая методичка](README.md) · [Стартовый файл](starter/cmd/task-cli/main.go)

Выполняйте работу в `cmd/task-cli/main.go` **своего прежнего** проекта `go-practice-01`. Сторонние пакеты и база данных не требуются.

## Обязательное задание

Реализуйте интерфейс `TaskStore` и хранилище `MemoryStore` с пятью методами:

| Метод | При успехе | При ошибке |
|---|---|---|
| `Add(title, priority)` | Создаёт Task с новым ID и статусом `new` | `ErrInvalid` для пустого названия или приоритета не в 1–3 |
| `Get(id)` | Возвращает найденный Task | `ErrNotFound` |
| `Complete(id)` | Переводит статус в `done` | `ErrNotFound` |
| `Delete(id)` | Удаляет задачу | `ErrNotFound` |
| `List()` | Возвращает копию списка | Ошибки нет |

Ошибки контекстуализируйте с `fmt.Errorf(... %w ...)`; распознавайте с `errors.Is`. ID увеличивайте только после успешного добавления; не выдавайте удалённые ID повторно.

Создайте меню: `1` добавить, `2` список, `3` завершить, `4` удалить, `0` выйти. Обрабатывайте неверные команды и ввод вместо аварийного завершения. В `run` используйте `defer` для прощального сообщения.

## Обязательные проверки

| Шаг | Действие | Ожидается |
|---|---|---|
| 1 | Показать список сразу после запуска | Пуст |
| 2 | Добавить `Изучить Go`, приоритет 2 | ID=1, статус new |
| 3 | Добавить название из одних пробелов | Ошибка, ID не расходуется |
| 4 | Добавить приоритет 0 и 4 | Ошибка |
| 5 | Добавить `Написать API`, приоритет 3 | ID=2 |
| 6 | Завершить ID=1 | Статус done |
| 7 | Завершить ID=1 повторно | Статус done, ошибки нет |
| 8 | Завершить ID=99 | Сообщение об отсутствующей задаче |
| 9 | Удалить ID=1 | Остался ID=2 |
| 10 | Удалить ID=1 снова | Ошибка ErrNotFound |
| 11 | Добавить новую задачу | ID=3 |
| 12 | Ввести неизвестную команду | Подсказка, цикл продолжается |
| 13 | Ввести 0 | Сообщение из defer и выход |

Дополнительно **в коде** проверьте `errors.Is(err, ErrNotFound)` для результата `Get(999)`, а также отсутствие влияния изменений возвращённого `List()` на внутренний список `MemoryStore`.

## Дополнительное задание

Добавьте команду `5`: поиск по ID через `Get`. Реализуйте фильтрацию списка по статусу. Объясните, как в следующей работе можно заменить `MemoryStore` файловым хранилищем, не меняя интерфейс.

## Критерии и сдача

- [ ] Все пять методов корректны и удовлетворяют интерфейсу.
- [ ] Есть проверка данных и уникальная выдача ID.
- [ ] Используются `error`, `%w`, `errors.Is`, а не проверка текста сообщения.
- [ ] Меню работает до выхода или EOF, не паникует на неверном вводе.
- [ ] `List` защищает внутреннее состояние от изменения извне.
- [ ] Проверены все 13 сценариев.
- [ ] Выполняются `go run ./cmd/task-cli`, `go build ./...`, `go vet ./...`.
- [ ] Обновлён README личного проекта и опубликован новый коммит.

На защите покажите цикл «добавить → список → завершить → удалить», некорректные аргументы и объясните назначение интерфейса.
