# Рабочий пример практической № 4

В этой папке — полностью работающая программа с `TaskStore`, `MemoryStore`, меню, `errors.Is` и `defer`. Откройте папку как отдельный проект:

```bash
go run .
go build ./...
go vet ./...
```

Пример ввода, по одной строке:

```text
1
Изучить Go
2
2
3
1
2
4
1
2
0
```

Данные существуют только во время работы программы. Самостоятельную ПР выполните с помощью [каркаса](../starter/README.md) в личном `go-practice-01`.
