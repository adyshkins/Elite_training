## Цель

Собрать небольшое консольное приложение и явно обрабатывать неудачные операции.

## Планируемая работа на занятии

1. Определить небольшой интерфейс работы с задачами и реализовать хранение в памяти.
2. Реализовать добавление, поиск, изменение и удаление задач.
3. Возвращать ошибки для неверных значений и отсутствующих задач; познакомиться с errors.Is.
4. Подключить простое меню на основе стартового каркаса; отдельно разобрать порядок выполнения defer.

## Ожидаемый результат

Консольное приложение с операциями над задачами и обработкой ошибок.

## Самостоятельная часть и расширение

Проверить полный цикл работы и улучшить сообщения об ошибках.
