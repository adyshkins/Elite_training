# Задания практической работы № 3

[Пошаговая методичка](README.md) · [Стартовый файл](starter/cmd/task-model/main.go)

Работайте в собственном `go-practice-01/cmd/task-model/main.go`. Старые программы оставьте без изменений. Новый `go.mod` не нужен.

## Обязательное задание

1. Определите `Task` с полями `ID int`, `Title string`, `Status string`, `Priority int`.
2. Реализуйте `Summary() string`, возвращающий `#2 Освоить функции [in_progress], приоритет 2` для соответствующего объекта.
3. Реализуйте `Complete()`, изменяющий статус **исходной задачи** на `done`.
4. Реализуйте `SetPriority(priority int) bool`: допускаются числа от 1 до 3, неверное значение ничего не изменяет.
5. Создайте срез из трёх объектов с ID 1, 2, 3 и данными из каркаса.
6. Реализуйте `findTaskByID(tasks []Task, id int) *Task`: возвращайте указатель на **элемент исходного среза** или `nil`.
7. Найдите ID=2, завершите её, поставьте приоритет 3.
8. Выведите все задачи через `Summary()` и число `Задач завершено: 2`.
9. Покажите сообщение `Задача не найдена` для отсутствующего ID=99.

## Сценарии проверки

| Сценарий | Ожидаемый результат |
|---|---|
| Поиск ID=2 | Получен ненулевой указатель |
| `Complete()` по ID=2 | Во **всём срезе** статус этой задачи `done` |
| `SetPriority(3)` | `true`, приоритет изменён |
| `SetPriority(0)` | `false`, прежний приоритет сохранён |
| `SetPriority(4)` | `false`, прежний приоритет сохранён |
| Поиск ID=99 | `nil`, без паники |
| Поиск в `[]Task{}` | `nil` |
| `Task{}` | Все поля имеют нулевые значения |

Временно изменяйте входные данные для проверок; перед сдачей восстановите исходный пример. Убедитесь, что незавершённые `TODO` не остались.

## Дополнительно
