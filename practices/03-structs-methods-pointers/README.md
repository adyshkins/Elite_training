## 1. Структура объединяет поля объекта

```go
type Task struct {
    ID       int
    Title    string
    Status   string
    Priority int
}

task := Task{ID: 1, Title: "Изучить Go", Status: "new", Priority: 2}
fmt.Println(task.Title)
```

`struct` создаёт тип с именованными полями. Незаполненный `int` равен `0`, `string` — пустой строке. Нулевые значения не обязательно допустимы для реальной задачи.

**Попробуйте:** создайте три объекта `Task` с разными ID и выведите их названия.

## 2. Методы: поведение объекта

```go
func (t Task) Summary() string {
    return fmt.Sprintf("#%d %s [%s], приоритет %d", t.ID, t.Title, t.Status, t.Priority)
}
```

Это метод с **получателем по значению** `t Task`: структура копируется. Он хорошо подходит для чтения данных. Вызов: `fmt.Println(task.Summary())`.

Сравните ошибочный и правильный способы изменить задачу:

```go
func (t Task) WrongComplete() {
    t.Status = "done" // меняется только копия
}

func (t *Task) Complete() {
    t.Status = "done" // меняется исходная задача
}
```

`*Task` — получатель-указатель. Для адресуемой переменной `task.Complete()` работает: Go автоматически берёт адрес. Метод `WrongComplete` — только иллюстрация, в итоговую работу его включать не нужно.

## 3. Значение, адрес, указатель и nil

```go
task := Task{ID: 1, Title: "Практика", Status: "new", Priority: 1}
copyTask := task
copyTask.Title = "Копия"
fmt.Println(task.Title) // Практика
ptr := &task
ptr.Priority = 3
fmt.Println(task.Priority) // 3
```

`&task` даёт адрес переменной; `*ptr` — значение по этому адресу. Указатель `nil` никуда не указывает. Прежде чем читать поля найденной задачи, проверяйте `found != nil`.

Реализуйте метод изменения приоритета:

```go
func (t *Task) SetPriority(priority int) bool {
    if priority < 1 || priority > 3 {
        return false
    }
    t.Priority = priority
    return true
}
```

Недопустимый приоритет должен вернуть `false` **без изменения** задачи. В четвёртой работе вместо `bool` освоим ошибки `error`.

## 4. Срез структур и поиск

```go
tasks := []Task{
    {ID: 1, Title: "Установить Go", Status: "done", Priority: 1},
    {ID: 2, Title: "Освоить функции", Status: "in_progress", Priority: 2},
    {ID: 3, Title: "Изучить структуры", Status: "new", Priority: 3},
}

for _, task := range tasks {
    fmt.Println(task.Summary())
}
```

При `for _, task := range tasks` переменная `task` содержит **копию** элемента. Для изменения самого среза обращайтесь через индекс:

```go
for i := range tasks {
    if tasks[i].ID == 2 {
        tasks[i].Complete()
    }
}
```

Напишите `findTaskByID(tasks []Task, id int) *Task`. При совпадении возвращайте `&tasks[i]`, иначе `nil`. Не возвращайте указатель на копию элемента цикла — тогда изменение не затронет исходный срез.

```go
found := findTaskByID(tasks, 2)
if found != nil {
    found.Complete()
}
```

## Типичные ошибки

| Ошибка | Причина |
|---|---|
| Объект не изменился | У метода получатель `Task`, а не `*Task` |
| Меняется только переменная `task` | В `range` используется копия |
| Падение при отсутствии ID | Проверьте указатель на `nil` |
| `main redeclared` | Положите новую программу в отдельную папку |
| `go.mod file not found` | Работайте из корня своего проекта |
