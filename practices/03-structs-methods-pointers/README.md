## Цель

Описать предметную область задачи и понять, когда метод изменяет исходный объект.

## Планируемая работа на занятии

1. Создать Task с идентификатором, названием, статусом и приоритетом.
2. Разобрать значение, адрес, указатель, nil и передачу аргументов.
3. Реализовать методы завершения задачи и изменения приоритета.
4. Обработать срез задач и сравнить получателей-значения и получателей-указатели.

## Ожидаемый результат

Модель задачи и операции изменения её состояния.

## Самостоятельная часть и расширение

Добавить поиск по идентификатору и вывод задач по статусу.
