# Пример к практической № 3

Полностью работающий пример модели Task. Откройте папку examples как отдельный проект:

```bash
go run .
go build ./...
go vet ./...
```

Не сдавайте пример преподавателя вместо собственного решения. Для самостоятельной работы используйте [каркас](../starter/README.md).
