# Краткий справочник ко второй практике

[К методичке](README.md) · [К заданиям](assignments.md)

Здесь собраны конструкции, которые понадобятся в `cmd/task-summary/main.go`. Это **короткие фрагменты кода для объяснения синтаксиса**, а не самостоятельные программы: чтобы запустить фрагмент, поместите его внутрь `func main()` или используйте [готовые примеры](examples/README.md).

## 1. Сравнение и логические выражения

| Оператор | Значение | Пример |
|---|---|---|
| `==` | равно | `status == "done"` |
| `!=` | не равно | `status != "new"` |
| `<`, `>`, `<=`, `>=` | сравнение чисел | `count >= 2` |
| `&&` | логическое И | `count > 0 && count < 10` |
| `||` | логическое ИЛИ | `count == 0 || count > 10` |
| `!` | логическое НЕ | `!found` |

Все выражения в условии `if` должны давать `bool`.

```go
if count == 0 {
    fmt.Println("Пусто")
} else if count < 5 {
    fmt.Println("Мало")
} else {
    fmt.Println("Много")
}
```

`else` пишется после закрывающей фигурной скобки предыдущего блока на **той же строке**: `} else {`.

## 2. `switch` для нескольких вариантов

```go
switch status {
case "new":
    return "Новая"
case "done":
    return "Завершена"
default:
    return "Неизвестный статус"
}
```

Это пример тела функции, которая возвращает `string`. Если `status` не равен ни одному указанному значению, работает `default`. У обычного `switch` ветки не проваливаются автоматически друг в друга.

## 3. Три способа написать `for`

**Со счётчиком:**

```go
for i := 0; i < 3; i++ {
    fmt.Println(i)
}
```

**С условием продолжения:**

```go
remaining := 3
for remaining > 0 {
    remaining--
}
```

**По элементам среза:**

```go
names := []string{"Проверить Go", "Написать функцию"}
for i, name := range names {
    fmt.Printf("%d. %s\n", i+1, name)
}
```

Чтобы не использовать индекс, замените его на `_`. Чтобы остановить цикл — `break`; чтобы перейти к следующей итерации — `continue`.

```go
for _, name := range names {
    if name == "" {
        continue
    }
    fmt.Println(name)
}
```

## 4. Функции и возвращаемые значения

```go
func isLong(text string, minLength int) bool {
    return len(text) >= minLength
}
```

Имя функции — `isLong`, параметры — `text` и `minLength`, тип ответа — `bool`. Вызов: `isLong("Go", 2)`.

**Важно:** `len` для строки считает **байты**, а не русские буквы. В нашей практике `len` используется прежде всего для **срезов**, где он даёт количество элементов. Обработку Unicode-строк изучим отдельно по необходимости.

Функция не обязана печатать ответ. `return` отдаёт значение вызывающему коду. Для функции с типом результата `int` недостаточно написать `fmt.Println(count)` вместо `return count`.

## 5. Массив, срез и `append`

```go
fixed := [2]int{3, 5}  // Массив: два элемента
numbers := []int{3, 5}  // Срез: длина может расти
numbers = append(numbers, 8)

fmt.Println(len(fixed))   // 2
fmt.Println(len(numbers)) // 3
```

`[2]int` и `[]int` имеют разные типы. `append` относится к срезам. Доступ к элементу — `numbers[0]`; обращаться к `numbers[len(numbers)]` нельзя: это за пределами среза.

Срезы при передаче в функцию не копируют все элементы автоматически. На этой практике функции **только читают** `statuses` и считают данные — они не меняют содержимое среза.

## 6. `map`: подсчёт частот и проверка ключа

```go
counts := make(map[string]int)
counts["new"]++
counts["done"] += 2

fmt.Println(counts["new"]) // 1
fmt.Println(counts["done"]) // 2
```

Значение отсутствующего ключа `map[string]int` при обычном чтении — `0`. Если нужно узнать, присутствует ли ключ на самом деле:

```go
value, exists := counts["blocked"]
fmt.Println(value, exists) // 0 false
```

**Порядок элементов `map` при переборе не задан.** Чтобы получить предсказуемый вывод, обращайтесь к известным ключам в нужной последовательности.

## 7. Типичные ошибки

| Ошибка | Как исправить |
|---|---|
| `if status = "done"` | В условии нужно сравнение `==` |
| `for i <= len(statuses)` и обращение по индексу `i` | Последний допустимый индекс — `len(statuses)-1`; используйте `i < len(statuses)` |
| `append(statuses, "new")` без присваивания | `statuses = append(statuses, "new")` |
| `return` заменено на `Println` | Верните значение из функции, печатайте в `main` |
| `counts[status]++` при объявлении `var counts map[string]int` | Создайте записываемую карту через `make` |
| Одинаковое имя `main` у двух файлов в одной папке | Держите каждую консольную программу в собственной подпапке `cmd` |
| Число завершённых задач введено вручную | Считайте циклом по данным, а не константой |
