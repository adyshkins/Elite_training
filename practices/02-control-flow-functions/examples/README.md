# Готовые примеры второй практики

[К практике № 2](../README.md) · [К заданиям](../assignments.md) · [Как получить файлы](../../../docs/how-to-use.md)

Здесь собраны **короткие работающие программы для разбора темы**. Они не являются готовым решением задания про сводку статусов.

## Как открыть и запустить

Если Git пока незнаком, воспользуйтесь [инструкцией скачивания ZIP](../../../docs/how-to-use.md#4-как-скачать-все-примеры-без-git).

1. Распакуйте скачанный архив курса.
2. В VS Code выберите **File → Open Folder** и откройте `practices/02-control-flow-functions/examples`.
3. Через **Terminal → New Terminal** откройте терминал. Выполните `pwd` и `ls`: здесь должен быть `go.mod`.
4. Выполняйте по одной команде:

| Пример | Что показывает | Команда из папки `examples` |
|---|---|---|
| [conditions/main.go](conditions/main.go) | `if / else`, `switch / case / default` | `go run ./conditions` |
| [loops/main.go](loops/main.go) | Три варианта `for`, индексы, `range` | `go run ./loops` |
| [functions/main.go](functions/main.go) | Параметры, возвращаемое значение, `return` | `go run ./functions` |
| [collections/main.go](collections/main.go) | Массивы, срезы, `append`, `map`, проверка ключа | `go run ./collections` |

Каждая подпапка — самостоятельная программа с собственной `func main()`. В общем каталоге `examples` уже есть `go.mod`. **Не запускайте `go mod init` повторно и не переносите все `main.go` в одну папку.**

## Что проверить вручную

- **Условия:** смените `status` на `new`, `done` и произвольное значение. Проверьте, куда попадает управление в `switch`. Поменяйте `attempts` на ноль.
- **Циклы:** измените порядок и количество статусов. Сравните результат обычного `for` и `for range`.
- **Функции:** вызовите `maxNumber(4, 9)` и `countPositive([]int{-3, 0})`. Сравните ответы с ожидаемыми.
- **Коллекции:** добавьте ещё один `new` с помощью `append`; проверьте счётчик. Затем замените запрос `blocked` на существующий ключ `done`.

В `map` нет гарантированного порядка перебора: для читаемой сводки используем **заранее выбранный порядок ключей**, а не порядок `range` по карте.

## Проверка примеров

В терминале **из этой папки**:

```text
go fmt ./...
go build ./...
go vet ./...
```

Для автоматической проверки всех примеров преподаватель может запускать [`scripts/check_practice_02.py`](../../../scripts/check_practice_02.py) из корня репозитория курса. **Python студенту не требуется.**

После знакомства с примерами вернитесь в **свой проект `go-practice-01`** и выполните [основное задание](../assignments.md). Не сдавайте вместо своей программы копию демонстрационного примера.
