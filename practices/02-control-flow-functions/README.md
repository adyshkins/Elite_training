## Цель

Научиться выбирать ветку выполнения, повторять действия, выделять функции и обрабатывать коллекции.

## Планируемая работа на занятии

1. Разобрать if, switch и основные варианты for на коротких программах.
2. Написать функции с параметрами и возвращаемыми значениями.
3. Обработать список строк: добавить элемент, найти совпадение, посчитать частоты через map.
4. Проверить обычные, пустые и граничные данные. Массивы сравнить со срезами на демонстрации.

## Ожидаемый результат

Небольшие программы с условиями, циклами, функциями, срезами и map.

## Самостоятельная часть и расширение

Закрепить отдельными упражнениями функции и коллекции; расширить программу без копирования одинаковых блоков.
