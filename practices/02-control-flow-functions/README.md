## Что вы научитесь делать

В первой практике вы создали программы с переменными и вводом. Во второй научитесь **управлять ходом выполнения программы**, повторять действия и работать с несколькими значениями сразу.

На занятии разберём `if`, `switch`, `for`, функции, массивы, срезы (`slice`) и словари (`map`). На их основе начнём собирать простую **сводку статусов задач**. В следующей практике объединим название, статус и другие свойства каждой задачи в структуру `Task`.

**К концу всей практики** у вас должна быть программа `cmd/task-summary/main.go` в **собственном проекте `go-practice-01`**. Она показывает список статусов, считает задачи по статусам и корректно работает с пустым списком. Исходники и новые изменения публикуются в вашем репозитории GitHub.

Предварительно нужно уметь открыть проект в VS Code, запустить `go run` и сохранить файл. Если вы пропустили предыдущее занятие, начните с [практики № 1](../01-introduction/README.md) и [настройки среды](../../docs/environment.md).

## 1. Условия: `if`, `else` и `switch`

Условие позволяет выполнить разный код в зависимости от значения. Например, задача считается завершённой, если её статус равен `"done"`.

```go
status := "done"

if status == "done" {
    fmt.Println("Задача завершена")
} else {
    fmt.Println("Задача ещё не завершена")
}
```

`==` проверяет **равенство**, а `=` присваивает новое значение. Условие должно иметь тип `bool`. В Go скобки вокруг условия необязательны, но **фигурные скобки тела обязательны**.

Если вариантов несколько, удобнее `switch`:

```go
switch status {
case "new":
    fmt.Println("Новая")
case "in_progress":
    fmt.Println("В работе")
case "done":
    fmt.Println("Завершена")
default:
    fmt.Println("Неизвестный статус")
}
```

`switch` выбирает первую подходящую ветку; в обычном `switch` Go автоматически завершает выбранную ветку, поэтому `break` после каждого `case` не нужен. `default` срабатывает, если ни одна ветка не подошла.

**Попробуйте:** откройте [`examples/conditions/main.go`](examples/conditions/main.go), измените `status` на `"new"`, `"done"` и `"blocked"`; проверьте разные ветки. Затем в собственной заготовке начните реализовывать `statusLabel(status string) string`, переводящую коды `new`, `in_progress` и `done` в русские подписи. Для остальных значений возвращайте `Неизвестный статус`.

## 2. Циклы: как обработать все элементы

В Go основная конструкция повторения — `for`. Она может выглядеть как цикл со счётчиком:

```go
for i := 0; i < 3; i++ {
    fmt.Println(i)
}
```

Программа выведет `0`, `1`, `2`. Здесь `i := 0` — начало, `i < 3` — условие продолжения, `i++` — увеличение счётчика. Индексы коллекций в Go начинаются с **нуля**.

Для обхода списка удобнее `for range`:

```go
statuses := []string{"new", "in_progress", "done"}

for i, status := range statuses {
    fmt.Printf("%d. %s\n", i+1, status)
}
```

`i` — индекс, `status` — значение на данной итерации, `i+1` — привычный человеку номер строки. Если индекс не требуется, используйте `_`:

```go
for _, status := range statuses {
    fmt.Println(status)
}
```

Go также разрешает `for condition { ... }` — цикл, похожий на `while` в других языках. Остановить цикл досрочно помогает `break`, а пропустить текущую итерацию — `continue`. Полный работающий образец — [`examples/loops/main.go`](examples/loops/main.go).

**Попробуйте:** посмотрите на цикл в `main()` заготовки. Он уже выводит элементы. После реализации `statusLabel` он покажет понятные подписи, а не текст-подсказку.

## 3. Массивы и срезы: хранение нескольких значений

**Массив** имеет размер, который входит в его тип. Ниже в массиве ровно три элемента:

```go
fixed := [3]string{"new", "in_progress", "done"}
fmt.Println(len(fixed)) // 3
```

**Срез** (`slice`) обозначается `[]string` без числа в скобках. Его длина может изменяться:

```go
statuses := []string{"new", "in_progress", "done", "done"}
statuses = append(statuses, "new")

fmt.Println(len(statuses)) // 5
```

`append` возвращает срез с добавленным элементом. **Сохраняйте результат обратно** в `statuses`: запись `append(statuses, "new")` без использования результата не подходит.

Срезы — основной способ хранить и передавать списки значений в Go. Массивы нужны реже, когда размер фиксирован. На данном занятии работаем со **срезом статусов**, а полноценные объекты задач появятся в практической № 3.

**Попробуйте:** найдите в своей заготовке создание `statuses`. Добавьте новый элемент `"new"` через `append` и запустите программу снова. Число строк должно увеличиться с четырёх до пяти.

## 4. Функции: не повторяем одинаковый код

Функция получает **параметры**, выполняет действия и при необходимости **возвращает результат**. Например:

```go
func maxNumber(a int, b int) int {
    if a > b {
        return a
    }
    return b
}
```

`maxNumber` — имя функции, `a` и `b` — параметры типа `int`, последний `int` указывает тип возвращаемого результата. `return` возвращает значение и завершает выполнение функции.

```go
result := maxNumber(7, 4)
fmt.Println(result) // 7
```

[Готовый пример функций](examples/functions/main.go) содержит ещё `countPositive(numbers []int) int`: цикл проходит по числам, увеличивает счётчик положительных и возвращает его. По такому же принципу можно считать статусы.

Теперь закончите функции из заготовки:

- `statusLabel(status string) string` возвращает русскую подпись через `switch`. Не выводите текст внутри функции: **верните** его с помощью `return`.
- `countStatus(statuses []string, target string) int` обходит срез через `for range` и возвращает число элементов, равных `target`. Для пустого среза результат равен `0`.

**Не путайте `return` и `fmt.Println`:** первое отдаёт значение вызывающему коду; второе печатает текст. В задании результат функции нужен для дальнейших вычислений и вывода из `main`.

## 5. `map`: считаем, сколько раз встретился каждый статус

`map` хранит пары **ключ → значение**. Здесь ключ — строка статуса, значение — число его появлений:

```go
counts := make(map[string]int)

for _, status := range statuses {
    counts[status]++
}

fmt.Println(counts["done"])
```

`make(map[string]int)` создаёт пустую карту, в которую можно записывать данные. Выражение `counts[status]++` увеличивает значение для ключа на один; если ключа ещё не было, числовое значение начинается с `0`.

Чтобы отличить отсутствующий ключ от существующего ключа со значением `0`, используйте форму:

```go
value, exists := counts["blocked"]
fmt.Println(value, exists)
```

**Важно:** порядок перебора ключей `map` через `range` **не гарантирован**. Поэтому в своей итоговой программе выводите статистику в явном порядке: `new`, `in_progress`, `done`. Пример — [`examples/collections/main.go`](examples/collections/main.go).

**Попробуйте:** добавьте в `main()` своей программы словарь `counts`, заполните его по `statuses` и выведите значения для трёх известных статусов.

## 6. Собираем итоговую программу

Откройте [условие задания](assignments.md#задание-1-сводка-статусов-задач) и проверьте, что в `cmd/task-summary/main.go` выполнены все `TODO`.

Для исходного набора из четырёх элементов и одного добавленного `"new"` результат должен содержать **такие строки в таком порядке**:

```text
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Статистика: new=2, in_progress=1, done=2
```

Если в коде всё ещё выводятся слова `Добавьте перевод статуса`, либо итог `Завершено: 0` для этого набора, программа не готова.

Из **корня `go-practice-01`** выполните:

```text
go run ./cmd/task-summary
go fmt ./...
go build ./...
go vet ./...
```

`go fmt` форматирует код, `go build` проверяет компиляцию, `go vet` ищет ряд типичных ошибок. Эти команды нужно выполнять **из своего проекта**, а не из папки с преподавательскими материалами.

> На занятии основной приоритет — разобраться в логике `if`, `switch`, `for`, функций и коллекций. Незаконченные `TODO` и проверки нестандартных данных входят в самостоятельную часть.

## Если что-то не работает

| Симптом | Как проверить |
|---|---|
| `no Go files` или `go.mod file not found` | Убедитесь через `pwd` и `ls`, что терминал открыт в корне своего `go-practice-01` |
| `main redeclared` | Не храните два файла с `func main()` в одной папке |
| `undefined: ...` | Проверьте имя функции/переменной, написание и область видимости |
| `declared and not used` | В Go локальные неиспользуемые переменные — ошибка компиляции |
| `index out of range` | Индексы начинаются с нуля; последний допустимый индекс — `len(slice)-1` |
| `cannot use ... as ...` | Проверьте тип: `[3]string` (массив) и `[]string` (срез) — не один тип |
| `assignment to entry in nil map` | Для записи создайте словарь через `make(map[string]int)` или литерал `map[string]int{}` |
| Карта выводится в разном порядке | Печатайте значения по заранее указанным ключам |
| Число задач не увеличилось | Проверьте `statuses = append(statuses, "new")` |
| Выводится текст из `TODO` | Замените заглушку рабочим кодом и сохраните файл |
