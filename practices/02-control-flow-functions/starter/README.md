# Заготовка для практики № 2

[К основному заданию](../assignments.md) · [К пошаговой методичке](../README.md)

В этой папке — **каркас программы, не готовое решение**. Строки `TODO` показывают, что нужно сделать: заполнить `switch`, написать цикл в функции, добавить элемент среза и построить словарь частот.

## Основной путь: продолжить проект из практики № 1

Если вы уже создали `GoProjects/go-practice-01`, **не создавайте новый модуль и не копируйте `go.mod` из этой папки**.

1. В VS Code откройте через **File → Open Folder** свой `go-practice-01`.
2. В дереве проекта внутри существующего `cmd` создайте папку `task-summary`, а в ней — файл `main.go`. Старые файлы не удаляйте.
3. Откройте [стартовый файл](cmd/task-summary/main.go) на GitHub, скопируйте **его полный текст** в свой `cmd/task-summary/main.go` и сохраните.
4. Откройте терминал из корня `go-practice-01` и запустите:

```text
go run ./cmd/task-summary
```

Каркас компилируется, но пока выводит `Добавьте перевод статуса` и считает ноль завершённых задач. **Это не правильный итог задания.** Выполните все `TODO` по [условию](../assignments.md).

## Альтернатива: самостоятельная копия starter

Только если нужно восстановить пропущенное занятие или первый проект недоступен:

1. [Скачайте ZIP курса](../../../docs/how-to-use.md#4-как-скачать-все-примеры-без-git) и распакуйте его.
2. Скопируйте **всю** папку `starter` из `practices/02-control-flow-functions/` в личную папку `GoProjects`. Переименуйте копию в `practice-02-solutions`. Существующий проект не перезаписывайте.
3. Откройте `practice-02-solutions` в VS Code. Здесь `go.mod` уже существует: `go mod init` не нужен.
4. Из корня копии выполняйте:

```text
go run ./cmd/task-summary
go build ./...
```

Это **альтернативный путь, а не вторая обязательная работа**. Для сдачи предпочтительно продолжить собственный GitHub-репозиторий первой практики. Не публикуйте под видом выполненной работы неизменённую заготовку.
