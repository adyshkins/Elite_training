## Задание 1. Сводка статусов задач

**Обязательное.** Реализуйте небольшую программу, которая хранит статусы учебных задач в срезе и выводит понятную сводку.

### Шаг 1. Исходные данные и добавление элемента

В `main()` создайте срез:

```go
statuses := []string{"new", "in_progress", "done", "done"}
```

Добавьте **ещё одну** задачу со статусом `new` через `append` и сохраните новый срез обратно в переменную `statuses`. В результате должно стать **пять** элементов.

Не заменяйте срез строкой `"new,in_progress,done"`. Нам нужна именно коллекция `[]string`.

### Шаг 2. Функция перевода статуса

Реализуйте функцию:

```go
func statusLabel(status string) string
```

Она получает один код и **возвращает** подпись. Используйте `switch` и `return`.

| Аргумент | Результат |
|---|---|
| `"new"` | `"Новая"` |
| `"in_progress"` | `"В работе"` |
| `"done"` | `"Завершена"` |
| Любое другое значение, в том числе пустая строка | `"Неизвестный статус"` |

Не используйте `fmt.Println` внутри этой функции: её задача — вернуть строку, а не напечатать её.

### Шаг 3. Нумерованный список

В `main()` выведите общее число элементов с помощью `len(statuses)`. Затем с помощью **`for range`** выведите каждый статус с номером от 1 в формате:

```text
1. Новая
2. В работе
```

Используйте функцию `statusLabel`, а не повторяйте `switch` в цикле. Длина и порядок вывода должны зависеть от данных, а не от пяти вручную написанных строк.

### Шаг 4. Функция подсчёта

Реализуйте вторую функцию:

```go
func countStatus(statuses []string, target string) int
```

Она должна пройти по `statuses`, посчитать элементы со значением `target` и **вернуть число**. Нельзя возвращать фиксированное `2` или использовать для ответа только заранее известное расположение значений.

В `main()` вызовите `countStatus(statuses, "done")` и выведите количество завершённых задач.

Для пустого среза результат должен быть **0**, для среза без `done` — тоже **0**.

### Шаг 5. Словарь частот

Создайте `counts` типа `map[string]int` и с помощью цикла посчитайте, сколько раз встречается каждый статус. Выведите статистику в **строго фиксированном порядке**:

```text
Статистика: new=2, in_progress=1, done=2
```

Значения берите из словаря. **Не печатайте всю карту одним `fmt.Println(counts)`**, так как порядок `map` не гарантирован. Не используйте заранее записанные числа вместо подсчёта.

### Ожидаемый результат

Для исходных четырёх значений и добавленного через `append` статуса `new` полный вывод должен быть:

```text
Задач всего: 5
1. Новая
2. В работе
3. Завершена
4. Завершена
5. Новая
Завершено: 2
Статистика: new=2, in_progress=1, done=2
```

Сверьте **все строки**, а не только число завершённых задач.

## Обязательная самостоятельная проверка

**Не переписывайте основную логику ради отдельного теста.** Временно измените только `statuses` и, где нужно, закомментируйте строку с `append`. После проверки верните исходный набор и добавление `new`. Запускайте программу заново после изменения и сохранения.

| Сценарий | Временно задайте `statuses` | `append` | Что проверить |
|---|---|---|---|
| 1. Обычный | `{"new", "in_progress", "done", "done"}` | Включён (`new`) | Всего 5, завершено 2, статистика 2/1/2 |
| 2. Пустой список | `[]string{}` | Временно отключён | Всего 0, ни одной нумерованной строки, завершено 0, частоты 0/0/0 |
| 3. Одна задача | `[]string{"done"}` | Временно отключён | Всего 1, завершено 1, частоты 0/0/1 |
| 4. Нет завершённых | `[]string{"new", "new"}` | Временно отключён | Всего 2, завершено 0, частоты 2/0/0 |

**Отдельно проверьте неизвестный статус.** Для этого **временно** добавьте в `main()` строку `fmt.Println(statusLabel("blocked"))` и убедитесь, что получаете `Неизвестный статус`. Аналогично проверьте `statusLabel("")`. После проверки удалите временные строки.

Проверьте, что программа не паникует на пустом срезе и не зависит от расположения отдельных статусов.

## Дополнительное задание. Поиск и доля завершённых

Необязательное. Приступайте после выполнения всех обязательных проверок.

**А. Поиск в срезе.** Напишите `findStatus(statuses []string, target string) int`. Функция должна вернуть **индекс первого совпадения** (начиная с нуля) или `-1`, если статус не найден. Протестируйте существующий и отсутствующий статус и пустой срез.

**Б. Доля выполненных задач.** Напишите `completionPercent(statuses []string) float64`. Вычислите `100 * число завершённых / число всех задач`, предварительно преобразовав целые значения в `float64`. **Обязательно** обработайте пустой срез: при нуле задач возвращайте `0` и не делите на ноль.

Эти функции должны работать с разными данными, а не только со стартовым примером.
