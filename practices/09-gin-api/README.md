## Цель

Создавать обработчики с удобной маршрутизацией и предсказуемыми ошибками.

## Планируемая работа на занятии

1. Перенести учебные маршруты на Gin и сгруппировать их.
2. Использовать параметры пути, query-параметры и JSON-тело.
3. Разделить входные структуры и данные ответа, проверить обязательные поля и допустимые значения.
4. Обработать некорректный JSON, неверный ID и отсутствие записи; ввести единый формат ошибки.

## Ожидаемый результат

Обработчики API с параметрами, валидацией и сообщениями об ошибках.

## Самостоятельная часть и расширение

Описать контракт маршрутов и набор некорректных запросов.
