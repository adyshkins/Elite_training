## Цель

Разделить ответственность компонентов и проверить поведение автоматически.

## Планируемая работа на занятии

1. Выделить handler, service, repository в готовом CRUD-приложении без лишних уровней абстракции.
2. Передать зависимости через конструкторы; определить небольшой интерфейс хранилища в месте использования.
3. Проверить бизнес-правила с тестовым хранилищем без настоящей БД.
4. Проверить HTTP-код и JSON через httptest в успешном и ошибочном сценариях.

## Ожидаемый результат

Структурированное приложение и автоматические проверки бизнес-логики и HTTP.

## Самостоятельная часть и расширение

Расширить табличные тесты и описать запуск. Интеграционные проверки БД оформлять отдельно от модульных.
