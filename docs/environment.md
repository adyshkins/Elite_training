# Настройка окружения

[К описанию курса](../README.md) · [К первой практике](../practices/01-introduction/README.md)

На первой практике нужны **Go и один редактор**. PostgreSQL, Docker, Git и веб-фреймворки пока не требуются. Не устанавливайте несколько сред ради одного занятия.

## 1. Инструменты

| Инструмент | Назначение |
|---|---|
| Go SDK | Компилятор, стандартная библиотека, команды запуска и сборки |
| VS Code + расширение Go или GoLand | Написание кода, подсказки и навигация |
| Терминал | Выполнение команд; PowerShell в Windows, Terminal в macOS/Linux или терминал редактора |

Установка редактора сама по себе не добавляет Go SDK. В GoLand SDK также нужно выбрать или загрузить при настройке проекта.

## 2. Установка Go

Откройте [официальную страницу загрузок](https://go.dev/dl/). Выберите **актуальный стабильный выпуск** для своей системы и архитектуры. Выпуски `beta` и `rc` для курса не нужны. Не ориентируйтесь на номер версии в старой статье или скриншоте.

`amd64` — вариант для 64-разрядных процессоров Intel/AMD; `arm64` — для ARM, в том числе Apple Silicon. Выбирайте архитектуру компьютера, а не по названию фирмы в имени файла.

### Windows

1. Скачайте установщик `.msi` для своей архитектуры.
2. Запустите его и завершите установку. Если на учебном компьютере нужны права администратора, обратитесь к преподавателю — не обходите ограничения самостоятельно.
3. Закройте и заново откройте PowerShell и редактор, если они были запущены до установки.
4. Выполните:

```powershell
go version
```

Команда должна вывести установленную версию и платформу. В выводе будет `windows`; номер версии зависит от установленного выпуска.

### macOS

1. Скачайте пакет `.pkg`: `arm64` для Apple Silicon или `amd64` для Intel.
2. Завершите установку.
3. Откройте новый терминал и выполните `go version`.

Если команда не найдена, проверьте шаги [официальной инструкции](https://go.dev/doc/install). Не копируйте настройки путей от другой системы.

### Linux

Сначала выполните `go version`: Go уже может быть установлен. Для установки используйте [официальную инструкцию](https://go.dev/doc/install), вкладку Linux. На компьютере аудитории системную установку и замену SDK согласуйте с преподавателем или администратором.

В инструкции отдельно описано добавление каталога команд Go в `PATH`. После установки откройте новый терминал и проверьте:

```bash
go version
```

Не распаковывайте новый SDK поверх старой установки и не запускайте команды удаления каталогов из интернета без понимания их назначения.

### Что не нужно настраивать вручную

Не меняйте `GOROOT` и не переносите проект в `GOPATH/src` по старым руководствам. В курсе используются Go Modules; проект можно создать в обычной доступной папке. Сейчас достаточно успешного `go version` и создания модуля по инструкции первой работы.

Источники: [установка Go](https://go.dev/doc/install), [первый модуль](https://go.dev/doc/tutorial/getting-started), [Go Modules](https://go.dev/ref/mod).

## 3. Основной вариант: VS Code

1. Установите [Visual Studio Code](https://code.visualstudio.com/Download).
2. Откройте **Extensions / Расширения**.
3. Установите расширение **Go** от **Go Team at Google**. Идентификатор — `golang.Go`; [официальная карточка](https://marketplace.visualstudio.com/items?itemName=golang.Go).
4. Через **File → Open Folder** откройте папку проекта, а не отдельный файл.
5. Откройте `.go`-файл. При предложении установить инструменты согласитесь на установку `gopls`.
6. Откройте **Terminal → New Terminal**, выполните `go version`.

`gopls` помогает редактору показывать подсказки и диагностику. Если загрузка не завершилась из-за сети, код можно писать и запускать через `go run` в терминале. Не отключайте проверку сертификатов и не устанавливайте случайные сборки расширений.

Можно включить **Editor: Format On Save**. Независимо от настроек перед сдачей выполняйте `go fmt ./...` из папки модуля.

В этой практике запускайте программы **через терминал**, а не через сторонний Code Runner: так видны команда и текущая папка, работает интерактивный ввод.

Источники: [Go в VS Code](https://code.visualstudio.com/docs/languages/go), [документация расширения](https://github.com/golang/vscode-go).

## 4. Альтернатива: GoLand

1. Установите [GoLand](https://www.jetbrains.com/go/download/) по [официальному руководству](https://www.jetbrains.com/help/go/installation-guide.html).
2. Откройте папку проекта или создайте Go-проект с поддержкой модулей.
3. В **Go → GOROOT** выберите установленный SDK. При необходимости используйте **Add SDK**. Старый тип проекта `Go (GOPATH)` для работы не нужен.
4. В терминале выполните `go version`.
5. Если GoLand уже создал `go.mod`, второй `go mod init` не нужен.

GoLand — альтернативная среда, а не обязательная покупка. Доступность и условия лицензии проверяйте у JetBrains; выполнение заданий не зависит от её наличия.

Источник: [создание проекта и выбор SDK](https://www.jetbrains.com/help/go/installing-and-configuring-goland.html).

## 5. Временно: Go Playground

[Go Playground](https://go.dev/play/) позволяет выполнять небольшие примеры в браузере. Скопируйте пример вывода или переменных и нажмите **Run**.

Это временный вариант, пока решается проблема с установкой. Ввод из обычного терминала и локальную сборку отрабатываем на компьютере. Для примера с `fmt.Scan` в Playground временно задайте значение прямо в коде.

Работа только в браузере не закрывает пункты об установке и `go build`.

## 6. Готовность к работе

Окружение готово, когда вы можете открыть папку в редакторе, выполнить `go version`, создать `main.go`, запустить программу и увидеть результат. Дальнейшие команды — в [первой практике](../practices/01-introduction/README.md).

При проблеме запишите команду, текущую папку, полный текст ошибки и вывод `go version`. Это полезнее сообщения «не запускается».
