# Установка Go и настройка редактора с нуля

[К описанию курса](../README.md) · [Вернуться к первой практике](../practices/01-introduction/README.md)

Эта инструкция заканчивается проверкой установки. **Создавать и открывать папку проекта будем после неё, в первой практике.** Пока никакого `main.go` у вас нет — это нормально.

## 1. Что устанавливаем и зачем

| Инструмент | Для чего он нужен | Ссылка |
|---|---|---|
| Go SDK | Превращает текст программы в исполняемую программу; предоставляет команду `go` | [Загрузить Go](https://go.dev/dl/) |
| Visual Studio Code, или VS Code | Редактор, в котором будем создавать файлы и писать код | [Загрузить VS Code](https://code.visualstudio.com/Download) |
| Расширение Go | Добавляет в VS Code поддержку языка, подсказки и диагностику | [Расширение `golang.Go`](https://marketplace.visualstudio.com/items?itemName=golang.Go) |

Go и VS Code — **две отдельные программы**. Установка расширения не заменяет установку Go SDK. **Visual Studio Code** и **Visual Studio** — разные продукты; в этом курсе нужен первый.

Для публикации проекта позже понадобится **Git**. Его установка описана в [разделе о GitHub](first-project-github.md). PostgreSQL, Docker, Python и веб-фреймворки на первом занятии устанавливать не нужно.

Основной маршрут — **VS Code + терминал**. С GoLand и другими вариантами можно познакомиться в конце этой инструкции; устанавливать несколько редакторов не требуется.

## 2. Определите свою систему

Выполните только раздел для своей операционной системы.

**Windows.** Откройте **Пуск → Параметры → Система → О системе** и найдите «Тип системы». Для 64-разрядной системы с процессором x64 выбирайте Go **Windows amd64**, для ARM64 — **Windows arm64**. `amd64` подходит и для соответствующих процессоров Intel: это название архитектуры, а не требование к производителю. При другой системе уточните совместимый вариант у преподавателя.

**macOS.** Откройте меню **Apple → Об этом Mac**. Для чипа Apple M-серии нужен Go **macOS arm64**, для процессора Intel — **macOS amd64**.

**Linux.** Дистрибутив и доступ к установке уточните у преподавателя или администратора аудитории. Не меняйте системное ПО учебного компьютера без разрешения.

На странице Go выбирайте **стабильный выпуск**, не `beta`, не `rc` и не исходный код. Не копируйте номер версии из старого скриншота: он может отличаться от актуального.

## 3. Windows: установить Go и выполнить первую команду

1. Откройте [загрузки Go](https://go.dev/dl/), найдите установщик **Windows** нужной архитектуры с расширением **`.msi`**.
2. Дождитесь загрузки и откройте этот файл из папки «Загрузки».
3. В мастере установки прочитайте условия, примите их для продолжения и нажимайте **Next → Install → Finish**. Путь установки без необходимости не меняйте.
4. Если система запрашивает права, которых у вас нет, обратитесь к преподавателю. Не обходите ограничения.
5. Закройте ранее открытые терминалы и VS Code. Это нужно, чтобы новые окна увидели установленный Go.
6. Нажмите **Пуск**, напишите `PowerShell` и откройте **Windows PowerShell**. Не выбирайте PowerShell ISE; запуск от администратора не требуется.
7. В открывшемся окне щёлкните по строке ввода, напишите команду ниже и нажмите **Enter**.

**Команда для PowerShell:**

```powershell
go version
```

**Как понять результат:** появится строка, начинающаяся с `go version go`, затем номер выпуска и платформа, например с окончанием `windows/amd64`. Номер зависит от установленной версии. Не вводите ожидаемый ответ вручную.

Если написано, что `go` не найден, закройте PowerShell и откройте заново. Если это не помогло, проверьте завершение установки и покажите преподавателю сообщение целиком. До устранения ошибки переходить к запуску кода не нужно.

## 4. Windows: установить VS Code

1. Откройте [страницу загрузки VS Code](https://code.visualstudio.com/Download).
2. Для личного компьютера выберите **Windows → User Installer** и подходящую архитектуру: **x64** или **Arm64**. При установке в аудитории следуйте правилам администратора.
3. Откройте скачанный `.exe`, прочитайте условия и завершите мастер установки. Стандартные параметры подходят для инструкции; пункт **Add to PATH** можно оставить включённым.
4. Запустите **Visual Studio Code** через меню «Пуск».
5. Экран приветствия и предложения войти в аккаунт можно закрыть: для написания первой программы вход в аккаунт редактора не нужен.

**Проверка:** открыто отдельное окно VS Code. Это приложение на компьютере, а не вкладка браузера.

## 5. macOS: установить Go и VS Code

1. Из [загрузок Go](https://go.dev/dl/) скачайте пакет `.pkg` для своей архитектуры.
2. Откройте пакет и пройдите мастер установки. При необходимости подтвердите установку своим системным паролем на личном компьютере; в аудитории обратитесь к администратору.
3. Нажмите **Cmd+Space**, введите `Terminal` и откройте приложение «Терминал».
4. В новом окне выполните `go version`: напишите команду и нажмите Enter. В ответе должна быть установленная версия и платформа `darwin/...`.
5. С [страницы VS Code](https://code.visualstudio.com/Download) скачайте вариант для macOS. Распакуйте архив, если это требуется, перенесите приложение в **Applications / Программы** и запустите его.

При ошибке установки используйте [инструкцию Go](https://go.dev/doc/install) и [инструкцию VS Code для macOS](https://code.visualstudio.com/docs/setup/mac). Не копируйте команды для Windows в терминал macOS.

## 6. Linux: подготовка с преподавателем

1. Откройте приложение «Терминал» из меню своей системы. Введите `go version` и нажмите Enter: Go уже может быть установлен.
2. Если команды нет, используйте [официальную установку Go для Linux](https://go.dev/doc/install) вместе с преподавателем или администратором. Там нужно правильно выбрать архив и настроить `PATH` — список папок, в которых система ищет команды.
3. VS Code установите по [официальной инструкции для своего дистрибутива](https://code.visualstudio.com/docs/setup/linux).
4. Откройте новый терминал и проверьте `go version`; затем запустите VS Code из меню приложений.

Самостоятельное удаление системных каталогов и распаковка нового Go поверх старого в эту практику не входят. Linux-установку здесь намеренно не сводим к одной универсальной команде: она зависит от компьютера. Если нет разрешения на установку, используйте согласованное рабочее место или временный вариант ниже.

## 7. Установите расширение Go в VS Code

Следующие шаги общие для всех систем.

1. В запущенном VS Code откройте **View → Extensions / Вид → Расширения**. В Windows/Linux можно нажать **Ctrl+Shift+X**, в macOS — **Cmd+Shift+X**.
2. В строке поиска расширений введите **`golang.Go`**.
3. Откройте карточку **Go**, издатель **Go Team at Google**. Сверьте её с [официальной карточкой](https://marketplace.visualstudio.com/items?itemName=golang.Go).
4. Нажмите **Install / Установить**, дождитесь завершения. Если предложена перезагрузка редактора, выполните её.
5. Закройте вкладку расширения. **Открывать `.go`-файл пока не нужно: мы ещё не создали его.**

Позже, при открытии первого `main.go`, расширение может предложить установить `gopls` — вспомогательный инструмент подсказок. Его установка описана на соответствующем шаге первой практики. При проблеме с сетью покажите ошибку преподавателю; запуск через команду `go run` не требует `gopls`.

## 8. Проверьте встроенный терминал

1. В VS Code выберите **Terminal → New Terminal / Терминал → Создать терминал**. Если меню скрыто, раскройте главное меню окна.
2. Внизу появится панель с вкладкой **TERMINAL**. Щёлкните внутри неё. Панель **OUTPUT / Вывод** и **DEBUG CONSOLE / Консоль отладки** для наших команд не подходят.
3. В Windows для этой инструкции используйте **PowerShell**. При другом варианте откройте стрелку рядом с `+` в панели терминала и выберите PowerShell.
4. Введите команду:

```text
go version
```

Нажмите Enter. Сравните результат с проверкой системного терминала. Если там команда работает, а здесь нет, полностью закройте и заново откройте VS Code.

Строка вида `PS C:\Users\...>` — приглашение к вводу, а не часть команды. Пишем **только** `go version`. Путь у каждого свой.

## 9. Что пока не нужно настраивать

Не создавайте вручную `GOROOT`, не переносите проект в `GOPATH/src`, не устанавливайте случайные пакеты из видеоуроков. Модуль создадим одной командой в своей папке. Настройки форматирования можно оставить стандартными; команду `go fmt` разберём в практике.

Для запуска не используем сторонний **Code Runner**. Сначала выполняем команды в терминале, чтобы видеть путь, команду, ввод и результат.

## 10. Другие варианты: для знакомства, не обязательная установка

**GoLand** — отдельная среда разработки. [Загрузка](https://www.jetbrains.com/go/download/), [установка](https://www.jetbrains.com/help/go/installation-guide.html), [первый проект и выбор SDK](https://www.jetbrains.com/help/go/installing-and-configuring-goland.html). В ней нужно выбрать Go SDK и папку проекта; если `go.mod` уже создан средой, повторять `go mod init` нельзя. GoLand не является обязательной покупкой; условия доступа проверяйте у разработчика. Новичкам на занятии достаточно основного пути с VS Code.

**Текстовый редактор + терминал** также позволяют писать и запускать Go, но в пошаговых инструкциях курса используется VS Code.

**[Go Playground](https://go.dev/play/)** — временный вариант в браузере: замените текст в поле полным примером программы и нажмите **Run**. Для запуска примера вывода достаточно браузера. Обычный ввод из терминала, настройку локального окружения и сборку исполняемого файла это не заменяет. В примере с `fmt.Scan` для Playground значение временно задают в коде.

## Проверка перед переходом к коду

- [ ] Go установлен, `go version` работает во встроенном терминале VS Code.
- [ ] Установлен один выбранный редактор и расширение Go.
- [ ] Вы различаете браузер, область редактирования файла и терминал.

**Теперь вернитесь к [первой практике, разделу «Создаём проект»](../practices/01-introduction/README.md#2-создаём-проект). Там сначала создадим папку, затем откроем её.**
