# Как открыть материалы и получить файлы

[К описанию курса](../README.md) · [Начать первую практику](../practices/01-introduction/README.md)

## 1. Откройте курс в браузере

Перейдите на [страницу курса «Бэкенд-разработка на языке Go»](https://github.com/adyshkins/Elite_training).

GitHub — сайт, на котором размещены файлы курса. Для **чтения этого открытого репозитория** регистрироваться и устанавливать Git не нужно. Учётная запись понадобится позже, для публикации собственного проекта.

Вверху страницы находится список папок и файлов. Ниже показан текст `README.md` — описание курса. Прокрутите страницу до таблицы практических работ и нажмите на название **практики № 1**. Откроется инструкция; читать её можно прямо в браузере.

Чтобы открыть файл вручную, нажимайте по очереди на папки и имя файла. Например:

```text
practices → 01-introduction → examples → hello → main.go
```

Это **путь к файлу на сайте**, а не команда для терминала.

## 2. Как копировать код из инструкции

В инструкции встречаются три разных вида блоков:

| Подпись или вид содержимого | Что с ним делать |
|---|---|
| **Код для `main.go`**; начинается с `package main` | Вставить в файл программы в редакторе |
| **Команда для терминала**; например `go run .` | Ввести в терминале и нажать Enter |
| **Ожидаемый результат**; например приветствие | Сравнить с выводом своей программы; вводить этот текст не нужно |

У блока кода на GitHub есть кнопка копирования. Можно также выделить сам текст и скопировать его. Не копируйте название языка над блоком, номера строк, обратные кавычки, приглашение терминала `PS ...>` или поясняющий текст вокруг примера.

**Не переводите код и команды переводчиком.** Переводить можно пояснения на английском.

## 3. Нужно ли скачивать весь репозиторий

**Для первой программы — нет.** Её папку и файл вы создадите самостоятельно по шагам первой практики. Не нажимайте `Fork`, `Codespaces` или `Open with GitHub Desktop`: для этого пути они не нужны.

Готовые примеры можно читать по ссылкам:

| Файл | Назначение |
|---|---|
| [Первая программа: `hello/main.go`](../practices/01-introduction/examples/hello/main.go) | Сверить свой первый код |
| [Переменные: `variables/main.go`](../practices/01-introduction/examples/variables/main.go) | Повторить основные типы и вывод |
| [Ввод: `input/main.go`](../practices/01-introduction/examples/input/main.go) | Посмотреть полный пример чтения числа |
| [Заготовка карточки](../practices/01-introduction/starter/cmd/card/main.go) | Начать самостоятельную задачу |
| [Заготовка конвертера](../practices/01-introduction/starter/cmd/time-converter/main.go) | Использовать подготовленный ввод с проверками |

На странице исходного файла кнопка **Raw** показывает только текст файла, без оформления GitHub. Для вставки кода достаточно обычного копирования; сохранять веб-страницу как HTML не нужно.

## 4. Как скачать все примеры без Git

1. Вернитесь на [главную страницу репозитория](https://github.com/adyshkins/Elite_training).
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**. Браузер скачает архив.
3. Откройте папку «Загрузки». В Windows нажмите правой кнопкой по архиву и выберите **Извлечь всё**; на macOS откройте архив двойным щелчком; в Linux используйте действие распаковки своего файлового менеджера.
4. Откройте **распакованную** папку. Внутри должна быть папка с `README.md`, `docs` и `practices`. Внешняя папка архива обычно называется `Elite_training-main`.
5. Храните её отдельно от своего проекта `go-practice-01`. Не запускайте программы прямо из окна просмотра ZIP.

Чтобы запустить готовые примеры, после установки Go и VS Code откройте через **File → Open Folder** папку `practices/01-introduction/examples` **внутри распакованного курса**. В ней уже есть `go.mod`. Затем следуйте [инструкции примеров](../practices/01-introduction/examples/README.md).

Скачанный ZIP — копия на момент скачивания. Он не обновляется автоматически и не содержит истории Git. Для новых материалов скачайте свежий архив в **другую папку**, не заменяя папку собственных решений.

## 5. Где писать собственный код

Материалы преподавателя и ваша работа — разные папки:

```text
Документы/
├── Elite_training-main/     ← скачанные материалы; могут вообще не понадобиться
└── GoProjects/
    └── go-practice-01/      ← здесь создаём и изменяем свой проект
```

Публиковать решение будем **в своём аккаунте GitHub**, а не в репозитории преподавателя. Как именно — в [инструкции первой публикации](first-project-github.md), после создания работающей программы.
