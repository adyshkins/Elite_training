# Выполнение и сдача практических работ

[К описанию курса](../README.md)

## Что считать выполненной работой

Выполните обязательные задания, проверьте указанные наборы данных и подготовьте исходный код. Дополнительные упражнения не заменяют обязательные и выполняются после основной части.

На демонстрации нужно запустить программу, объяснить её устройство и ответить на вопросы по использованным конструкциям. Готовый пример из учебного репозитория сам по себе не является решением самостоятельного задания.

## Где хранить решения

Учебный репозиторий содержит материалы преподавателя. Храните решения в отдельной папке или собственном репозитории. Отправлять их в `adyshkins/Elite_training` через коммиты или pull request не требуется.

До знакомства с Git допустим ZIP-архив с исходниками. После занятия по Git используйте свой учебный репозиторий. Передайте архив или ссылку преподавателю на занятии; отдельная система сдачи здесь не вводится. Для приватного репозитория проверьте, что преподаватель имеет доступ.

Не публикуйте токены, пароли, `.env` с настоящими значениями, чужие персональные данные и рабочие базы. Для примеров используйте вымышленные данные.

## Состав результата

В папке работы должны находиться исходные `.go`-файлы, `go.mod` и, когда появятся зависимости, `go.sum`. Добавьте небольшой `README.md` с описанием запуска и выполненных пунктов. Исполняемые файлы, каталоги IDE, временные файлы и скачанные зависимости в архив не нужны.

Пример описания:

```markdown
# Практическая работа № 1

## Окружение
- Операционная система: ...
- Версия Go: ...
- Редактор: ...

## Выполнено
- ...

## Запуск
Команды запуска каждой программы из папки с go.mod.

## Проверка
Входные данные и результаты, включая граничные случаи.
```

Отдельный многостраничный отчёт Word не требуется. Скриншоты могут дополнить работу, но не заменяют исходники и команды запуска.

## Перед сдачей

Проверьте, что команды выполняются из указанных папок, код сохранён и отформатирован, обязательные сценарии работают. Запуск не должен зависеть от ваших личных файлов или секретов.

Если часть задания не выполнена, укажите её явно. При использовании заготовки поясните, что добавлено вами. Критерии конкретной практики имеют приоритет над общими правилами.

## Исправления и пропуски

Исправляйте своё решение, не подменяя его готовым примером. Пропущенную тему восстановите по инструкции и примерам. Стартовый код для следующей работы используйте, только если он опубликован в соответствующей папке.
