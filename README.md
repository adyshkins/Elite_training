# Бэкенд-разработка на языке Go

Практический курс для групп **Элитной подготовки**. Здесь находятся задания, примеры кода, инструкции по настройке инструментов и материалы для самостоятельной работы.

**Формат курса — 12 практических занятий по 90 минут. Отдельных лекций нет:** необходимые объяснения включаются в практические работы и сразу закрепляются в коде.

> **Начать обучение:** [практическая работа № 1 — инструменты и первая программа](practices/01-introduction/README.md).
>
> **Состояние материалов:** первая практика разработана полностью. Для практик № 2–12 опубликованы планы: темы, предполагаемые задания и результаты. Это ещё не готовые пошаговые методички.

## О курсе

Начинаем с установки Go и первых консольных программ. Затем учимся организовывать код, обрабатывать ошибки и сохранять данные. Во второй части курса переходим к PostgreSQL и разработке HTTP API.

Учебная линия курса — **система управления задачами**: от объектов в памяти и консольных команд до серверного приложения. В первой работе используются отдельные небольшие программы; предметную область начинаем собирать после знакомства с базовыми конструкциями языка.

К завершению курса целевой результат — небольшой бэкенд на **Go, Gin, GORM и PostgreSQL**: связанные сущности, CRUD-операции, проверка входных данных, обработка ошибок и базовые автоматизированные тесты. Объём самостоятельной части и дополнительных задач указан в конкретной практике.

## Что нужно для старта

Достаточно компьютера, доступа в интернет для установки инструментов и возможности работать в терминале. Умение программировать на другом языке полезно, но знание Go заранее не требуется.

На первом занятии нужны только **Go и один редактор**. Основной вариант в инструкциях — VS Code с расширением Go; GoLand можно использовать как альтернативу. Git, PostgreSQL и остальные инструменты подключаем тогда, когда они понадобятся. Сразу устанавливать весь стек не нужно.

## Как пользоваться материалами

Откройте папку нужной практики и прочитайте её `README.md`. В готовой работе указаны цель, необходимые инструменты, порядок действий, обязательные задания, дополнительные упражнения и критерии проверки.

**Примеры и собственные решения храните раздельно.** Примеры нужны для разбора, а самостоятельные задания — для закрепления. До занятия по Git можно работать в обычной локальной папке и передавать исходники архивом. После знакомства с Git решения удобно вести в своём учебном репозитории; отправлять их в этот общий репозиторий не требуется.

### Получение файлов

Без Git: на странице репозитория выберите **Code → Download ZIP**, распакуйте архив и откройте папку нужной практики. Для запуска одной первой программы скачивать весь репозиторий необязательно — её можно создать по инструкции.

С установленным Git:

```bash
git clone https://github.com/adyshkins/Elite_training.git
cd Elite_training
```

Получение обновлений, если учебные файлы не менялись локально:

```bash
git pull --ff-only
```

При конфликте с собственными изменениями сначала сохраните свою работу и обратитесь к преподавателю. Не используйте команды принудительного сброса, если не понимаете, какие файлы будут потеряны.

### Запуск примеров первой работы

Из корня скачанного репозитория:

```bash
cd practices/01-introduction/examples
go run ./hello
go run ./variables
go run ./input
```

Для последней программы введите целое неотрицательное число в терминале. Подробности — в [описании примеров](practices/01-introduction/examples/README.md).

**В корне репозитория нет общего `go.mod`.** Примеры и стартовые проекты — отдельные учебные модули. Команды `go run`, `go build` и `go test` выполняются из папки соответствующего модуля, а не из корня всего курса.

## Как проверяется работа

Основной результат — **работающий исходный код и понимание своего решения**. На проверке нужно запустить программу, показать несколько наборов данных и объяснить ключевые строки. Скриншоты могут дополнять результат, но не заменяют исходники.

Подробные требования описаны в [правилах сдачи](docs/submission.md); критерии конкретной практики имеют приоритет. Дополнительные задания выполняются после обязательной части.

Об ошибке в инструкции или примере можно сообщить через [Issues](https://github.com/adyshkins/Elite_training/issues). Укажите номер практики, шаг, ожидаемый результат, текст ошибки и версии инструментов. Не публикуйте пароли, токены и персональные данные.

## Проверка учебных примеров

Для сопровождающего курса предусмотрен скрипт `scripts/check_examples.py` (Python 3.9+ и Go). Он проверяет форматирование, сборку, `go vet` и семь сценариев запуска примеров первой работы. Он не проверяет решения студентов и не нужен для выполнения занятия.

```bash
python scripts/check_examples.py
```
