# Бэкенд-разработка на языке Go

Практический курс для групп **Элитной подготовки**. Здесь находятся задания, примеры кода, инструкции по настройке инструментов и материалы для самостоятельной работы.

**Формат — 12 практических занятий по 90 минут. Отдельных лекций нет:** объяснения включены в практические работы и сразу закрепляются в коде.

> **Первый раз на GitHub?** Начните с [инструкции по чтению материалов и получению файлов](docs/how-to-use.md).
>
> **Начать обучение:** [практика № 1 — от установки Go до первой публикации на GitHub](practices/01-introduction/README.md).
>
> **Состояние материалов:** первая практика содержит полное пошаговое задание. Для практик № 2–12 опубликованы планы: темы, предполагаемые задания и результаты, а не готовые методички.

## О курсе

Начинаем с установки Go, знакомства с редактором и первых консольных программ. Затем учимся организовывать код, обрабатывать ошибки и сохранять данные. Во второй части курса переходим к PostgreSQL и HTTP API.

Учебная линия — **система управления задачами**: от объектов в памяти и консольных команд до серверного приложения. В первой работе используются отдельные небольшие программы; предметную область начинаем собирать после знакомства с базовыми конструкциями языка.

Целевой результат курса — небольшой бэкенд на **Go, Gin, GORM и PostgreSQL**: связанные сущности, CRUD-операции, проверка данных, обработка ошибок и базовые автоматизированные тесты. Самостоятельная часть и дополнительные задачи указываются в конкретной практике.

## Что нужно для старта

Нужны компьютер и доступ к интернету для установки инструментов и публикации. **Предварительное знание Go, терминала, настройки IDE, Git и GitHub не требуется.** Эти действия разобраны с нуля. Опыт программирования на другом языке может помочь, но не заменяет объяснения новых инструментов.

Основной путь инструкций — **VS Code + расширение Go + Go SDK**. В первой практике также устанавливаем Git и знакомимся с GitHub. Регистрация на GitHub нужна для своего репозитория, но не для чтения открытых материалов курса. GoLand рассматривается как альтернатива, не обязательная покупка. ## Как работать с курсом

Откройте нужную практику и следуйте её `README.md` сверху вниз. Если шаг ведёт в отдельную инструкцию, после её выполнения вернитесь по обратной ссылке. У команд указана рабочая папка; у программ — имя файла и ожидаемый результат.

**Материалы преподавателя и собственные решения храните отдельно.** Первая программа создаётся вручную в `GoProjects/go-practice-01`. Карточка и конвертер расширяют этот же проект. Репозиторий для решений размещается в своём аккаунте, а не в `adyshkins/Elite_training`.

Для первой программы скачивать весь курс не нужно. Готовые примеры и стартовые файлы доступны по ссылкам из практики. [Получение файлов без Git, с объяснением распаковки ZIP](docs/how-to-use.md).

### Для тех, кто уже знаком с Git

Этот способ не является предварительным требованием для первого занятия. В терминале из папки, где хотите хранить **материалы курса**, можно выполнить:

```bash
git clone https://github.com/adyshkins/Elite_training.git
cd Elite_training
```

Для получения обновлений, если учебные файлы не менялись локально, из этой копии репозитория:

```bash
git pull --ff-only
```

При конфликте с собственными изменениями сначала сохраните свою работу и обратитесь к преподавателю. Не используйте принудительный сброс или перезапись истории без понимания последствий.

### Запуск готовых примеров

Новичкам: [открытие папки примеров и запуск по шагам](practices/01-introduction/examples/README.md).

Для знакомых с терминалом, **из корня скачанного или клонированного курса**:

```bash
cd practices/01-introduction/examples
go run ./hello
go run ./variables
go run ./input
```

Выполняйте по одной строке. Для последней программы введите целое неотрицательное число в том же терминале.

**В корне всего курса нет общего `go.mod`.** Примеры и стартовый проект — отдельные модули. Команды Go выполняют из соответствующей папки, а не из корня `Elite_training`. В собственном проекте первой практики, напротив, используем один `go.mod` и отдельные программы в `cmd`.

## Как проверяется работа

Основной результат — **работающий исходный код и понимание решения**. На проверке нужно запустить программу, показать несколько наборов данных и объяснить ключевые строки. Скриншоты могут дополнять, но не заменяют код.

В первой работе также показываем первый и следующий коммиты и опубликованный проект. При проблеме с доступом к GitHub порядок временной проверки указан в [правилах сдачи](docs/submission.md). Критерии конкретной практики имеют приоритет.

## Документация и сообщения об ошибках

[Полезные ссылки](docs/resources.md) сгруппированы по задачам. В каждой практике есть ссылки на конкретные файлы и первоисточники: короткие руководства идут раньше справочной документации.

Об ошибке в материале можно сообщить преподавателю на занятии или через [Issues](https://github.com/adyshkins/Elite_training/issues). Укажите номер практики, шаг, команду, ожидаемый результат, текст ошибки и версии инструментов. Не публикуйте пароли, токены и персональные данные.

## Проверка учебных примеров — для сопровождающего курса

Скрипт `scripts/check_examples.py` требует Python 3.9+ и Go. Он проверяет форматирование, сборку, `go vet` и семь сценариев запуска готовых примеров. Это не проверка решений студентов, и Python для выполнения первой практики **не требуется**.

Из корня курса в среде, где установлен Python:

```text
python scripts/check_examples.py
```
